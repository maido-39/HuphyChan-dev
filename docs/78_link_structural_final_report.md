# 전신 링크 구조 해석 — 최종 리포트 (2026-08-17)

해석 리비전 `2026-08-17b` · 재료 6061-T6 (항복 276 MPa) · 하중 = RL 정책 측정 P99 × 1.25
자동 생성 표: [fea_verdicts_current.md](fea_verdicts_current.md) · 방법론·실패 기록: [77장](77_structural_fea_lightweighting.md)

## 1. 한 줄 결론

**앞발 접지(toe-off) 조건의 발을 제외한 6개 링크는 모두 SF>2를 통과한다.** 발은 SF 0.95로
유일한 미달이며, 메시 수렴·하중 스케일·영역 크기 세 가지로 확인된 **실제 부족**이다.
그 외에 즉시 반영해야 할 항목은 **세 플랜지의 전단 다월핀**이다.

피크와 구조 전반의 응력 수준을 구분하기 위한 값이다.

## 3. 유일한 미달: 앞발 하중 하의 발

원래 스펙에는 **뒤꿈치 접지만** 있었다. 발목축이 y=145이고 앞발 접지는 100–180 mm 레버,
뒤꿈치는 0–80 mm이므로 뒤꿈치 케이스는 구조적으로 **약한 조건**이다. 앞발 케이스를 추가하자
19.4 → 289.5 MPa로 판정이 뒤집혔다.

세 가지로 확인했다.

1. **메시 수렴** — 취약 대역을 2.6 mm로 세분화: 287.1 MPa (기존 289.5, **0.8 % 차이**).
2. **영역이지 특이점이 아님** — 허용치 초과가 표면 절점의 1.54 %(3553개), 확장 125 mm,
   본체 p99가 145 MPa로 다른 링크(6–21 MPa)의 7–20배.
3. **하중을 낮춰도 미달** — 선형이므로 toe-off 실 GRF(1.0–1.2 BW)로 스케일하면 188 MPa → SF 1.47.

**원인**: 밑창은 두께 **정확히 8.0 mm**, 폭 100 mm의 평판인데 발목 지지가 x −161…−86,
y 127…195의 **좁은 영역**에 몰려 있다. 하중이 앞발에서 그 좁은 지지부로 대각선으로 모이며
측면 가장자리가 굽힘과 비틀림을 함께 받는다(최대점은 자유단에서 9.9 mm, 가장 가까운 볼트
구멍이 44 mm 떨어져 있어 구멍 집중이 아니다). 순수 보 이론의 공칭값은 106 MPa로, FEA의
2.7배 차이가 바로 이 좁은 지지부 효과다.

**조치**: 밑창 앞부분(x −169…−79, y 40…126, 하면 8 mm 층)
→ 두께 **×1.32**(SF>2) / ×1.14(SF>1.5), **또는 발목 마운트에서 앞발까지 길이방향 리브**.
하중경로가 대각선이므로 리브가 두께 증가보다 효율적이다. 변형도 함께 본다:
같은 조건에서 밑창 앞단 처짐이 **5.33 mm**로, 강도뿐 아니라 강성 문제이기도 하다.

## 4. 모터 강체 브래킷 — 판정을 뒤집는 모델링 선택

액추에이터 하우징은 메시화가 불가능해 **강체** 또는 **부재** 두 극단으로만 모델링된다.
강체는 병렬 하중경로를 만들어 응력을 낮추고, 부재는 하중을 볼트패드에 직접 떨어뜨린다.

| 링크 | 모터 포함 (하한) | 모터 제외 (보수) | 배율 | 보수 케이스 초과 절점 / 본체 p99 |
|---|---|---|---|---|
| L2 정강이 | 60.4 (SF 4.57) | 194.0 (SF 1.42) | ×3.21 | 8개 / 39.1 MPa |
| L3 대퇴 | 52.7 (SF 5.24) | 185.8 (SF 1.49) | ×3.53 | 2개 / 37.5 MPa |
| L5 힙 | 74.3 (SF 3.71) | 109.4 (SF 2.52) | ×1.47 | 0개 / 37.2 MPa |
| L6 골반 | 82.8 (SF 3.33) | 342.6 (SF 0.81) | ×4.14 | 4개 / 13.1 MPa |

보수적 경계의 피크는 **전부 2–8절점**이고 본체 p99는 13–39 MPa에 머문다. 즉 하우징을 빼면
렌치가 볼트패드 몇 절점에 직접 떨어지며 생기는 **하중 도입 집중**이지 구조가 무너지는 것이
아니다. L5는 보수적 경계에서도 SF>2를 통과한다.

→ **다음 정밀화 1순위**: 하우징을 실제 강성(알루미늄 케이스 + 플랜지 볼트)으로 모델링.

## 5. 체결부 — 즉시 반영 필요

| 체결면 | 볼트 | 인장/예압 | 분리여유 | 전단 (힘+비틀림) | **마찰여유** | 볼트전단 |
|---|---|---|---|---|---|---|
| L2 무릎 플랜지 | 6×M5 | 1212/2386 N | 1.97 | 1610 N (161+**1601**) | **0.26** | 1.27 |
| L5 힙 플랜지 | 6×M5 | 974/2386 N | 2.45 | 1183 N (132+**1175**) | **0.42** | 1.73 |
| L4 힙롤 플랜지 | 6×M5 | 1399/2386 N | 1.71 | 445 N (120+**429**) | **0.78** | 4.59 |
| L2 발목 하우징 | 8×M4 | 16/1475 N | 95.4 | 284 N | 1.80 | 4.45 |
| L5·L6 M4 그룹 | 10×M4 | 14–173/1475 N | 8.5–36 | 225–239 N | 2.0–2.1 | 5.3–5.6 |

- **분리 없음**(최소 1.71), **볼트 전단 파단 없음**(최소 1.27).
- 그러나 세 플랜지에서 **마찰이 부족**하다. 전단의 대부분이 **플랜지 법선 둘레의 비틀림**이며,
  베어링 시트 같은 센터링 레지스터는 면내 힘만 형상으로 받고 **자기 축 둘레 토크는 못 받는다**.
  그래서 레지스터를 가정해도 0.26 → 0.26으로 개선이 없다.
- 예압으로도 못 푼다: 알루미늄 탭이 상한이라 $SF_{thread}$를 2 → 1.5로 낮춰도 0.35.

**조치**: L2 무릎·L5 힙·L4 힙롤 플랜지에 **전단 다월핀 2개씩**(L5에는 이미 도웰 보어 2개 있음).
정적 파단이 아니라 수백만 보행 사이클의 **프레팅·풀림** 사안이다.

## 8. 남은 불확실성

1. 측정 렌치의 **모멘트 성분**은 docs/64 §8i 기준점 버그로 사용하지 않았다(굽힘은 실제 부착
   기하가 생성). 발목 M 재계산은 미완.
2. L1b는 **P99 GRF 전량을 앞발에** 실은 보수적 조건이다. CoP가 앞발일 때의 GRF 동시분포를
   측정에서 뽑으면 정밀해진다(§3의 스케일 논증이 그 상한을 이미 커버).
3. 액추에이터 하우징은 강체/부재 두 극단(§4).
4. 볼트 검토는 정적 미끄럼만 본다(피로 별도).
5. CAD 지적: L3 허브 z=−96 핀 3개 간섭(0.45 cm³, 해석에서 제외), ISO 4762 4.6 → 8.8 승급 시
   M4 20개가 알루미늄 탭 강도를 초과.

## 9. 조치 우선순위

1. **밑창 앞부분 보강** — 길이방향 리브 또는 두께 ×1.32 → **재해석 필수**
2. **L2·L4·L5 플랜지 전단 다월핀**
3. **하우징 실제 강성 모델링** → 브래킷 폭 축소 → 경량화 확정
4. 앞발 CoP-GRF 동시분포 측정 → L1b 하중 현실화
5. L3 허브 핀 간섭 수정
