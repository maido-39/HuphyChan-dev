# 82. 최종설계 질량표 검토 (2026-08-20)

사용자가 노트에 확정 기재하기 전 검토를 요청한 표. **산술은 전부 통과**했고, 물리적
정합성에서 **확정 3건 + 확인요청 3건**이 나왔다.

![mass table review](img/mass_table_review.png)

> 왼쪽: 링크별 질량을 분류로 쌓은 것(빨강 ×2 = 미러 측에도 필요한 링크).
> 가운데: 표가 편측이라는 근거. 오른쪽: 모터 토크밀도 — RS00·RS02가 추세를 깬다.

## §1 산술 — 전부 통과 (오차 ≤ 0.001 kg, 반올림)

| 검사 | 결과 |
|---|---|
| 링크 14행 합 vs 선언 총합 | 31.021 = 31.021 ✅ |
| 분류 4행 합 | 31.022 (+0.001, 반올림) ✅ |
| 링크별 파츠 내역 합 vs 링크 질량 | 14개 전부 |Δ| ≤ 0.001 ✅ |
| 분류 재집계(내역→분류) | 액추 17.700 / 알루 10.518 / 베어링 1.836 / 나사 0.966 ✅ |
| 백분율 | 14행 전부 표기값과 일치 ✅ |

**계산은 그대로 써도 된다.** 이하는 계산이 잡을 수 없는 것들이다.

## §2 ★확정 1 — 이 표는 **편측**이다. 로봇 총질량은 31.02 kg가 아니다

액추에이터 재고가 증거다. 표에 **모터 15개**(RS04 4 · RS03 6 · RS02 2 · RS00 3)가 있는데,
이 DoF 구성의 완성체는 다리 6×2 + 팔 5×2 + 허리 2 + 목 2 = **26개**가 필요하다.
다리·팔 링크가 각각 **한 벌씩만** 올라와 있다.

| | kg |
|---|---|
| 표 그대로 | 31.021 |
| + 미러 다리·팔 링크 | +18.373 |
| + 미러 모터(CenterParts의 Hip_R, WaistYaw2Pitch의 Elbow_Yaw) | +2.562 |
| **= 좌우 완성 추정** | **51.956** |

RL 심 모델 총질량 **51.527 kg** 대비 **+0.83 %**. 두 경로가 독립인데 1 % 안에서 만난다 —
편측 해석이 맞다는 강한 방증이다.

★**"로봇 총 질량: 31.02kg"는 이대로 노트에 넣으면 안 된다.** "편측 + 중앙 = 31.02 kg,
좌우 완성 ≈ 51.96 kg"로 쓰는 것이 맞다. (반대로 31.02가 정말 완성체라면 로봇이 20 kg
가벼워진 것이고, 캠페인의 모든 하중이 무효가 된다.)

## §3 ★확정 2 — RS00·RS02 질량이 물리적으로 불가능하다

토크밀도는 자석·감속비가 정하는 물리량이라, 표 값이 카탈로그와 어긋나면 눈에 띈다.

| 모터 | peak | 표 kg | 카탈로그 kg | 차이 | 표 N·m/kg | 카탈로그 N·m/kg |
|---|---|---|---|---|---|---|
| RS04 | 120 | 1.558 | 1.42 | +9.7 % | 77.0 | 84.5 |
| RS03 | 60 | 0.932 | 0.88 | +5.9 % | 64.4 | 68.2 |
| RS02 | 17 | **1.432** | (미기록, "소형") | — | **11.9** | — |
| RS00 | 14 | **1.004** | **0.31** | **+224 %** | **13.9** | 45.2 |

- RS04 +9.7 %, RS03 +5.9 %는 **정상 범위**다(케이블·어댑터·풀리 포함으로 설명된다).
- **RS00 1.004 kg은 카탈로그 310 g의 3.2배**다. 14 N·m 모터가 60 N·m RS03(0.932)보다
  무겁다는 뜻이라 성립하지 않는다.
- **RS02 1.432 kg**은 17 N·m에 11.9 N·m/kg — RS04(77)·RS03(64) 대비 5배 낮다. RS02는
  docs/36에서 "소형"으로 분류된 모터다.
- 카탈로그 출처: RS04 = [[33_knee_actuator_landscape]] (120/1.42 = 84.5 N·m/kg),
  RS03 880 g = [[37_ankle_linkage_fidelity]]·[[39_ankle_qdd_uptorque_survey]],
  RS00 310 g = [[36_all_actuator_tn_envelopes]]·[[39_ankle_qdd_uptorque_survey]].

**추정 원인**: 두 소형 모터의 STEP에 실제 질량속성이 없어 솔리드 체적×기본 밀도로 잡혔을
가능성이 크다. RS00·RS02의 CAD 질량속성 출처를 확인할 것. 영향: **목 3.058 → 약 1.7 kg,
WaistYaw2Pitch 2.163 → 약 0.8 kg** 수준으로 내려간다(총 −2.9 kg 규모).

## §4 ★확정 3 — `Ankle2Feet`는 링크가 아니라 **2-RSU 기구 전체**다

표는 이 그룹을 한 행(3.818 kg)으로 잡았지만, 솔리드 31개는 **하나의 강체가 아니다.**

| 증거 | 값 |
|---|---|
| 그룹의 z 범위 | **−503.7 ~ −839.0 mm** (발목 축 −800을 가로지름) |
| 크랭크 2개 | z = −503.7, −602.5 (= 발목 모터 높이, **정강이**) |
| 푸시로드 2개 | z = −697.9, 62.05 cm³ ×2 |
| JMC-JS06 로드엔드 | **정강이쪽** Ankle-A/B −523/−616 · **발쪽** FEET-A/B −810 |
| 발판 | z = −839.0 (197.6 cm³) |

★**캠페인이 `L1_ankle_foot`으로 푼 262.0 cm³ = 발판 솔리드 4개 262.07 cm³.** 구조 판정이
붙어 있는 물체와 기하학적 발이 정확히 같다. 나머지 307 cm³는 발이 아니다.

기하로 분해하면(로드는 병렬기구 관례대로 50/50):

| | kg |
|---|---|
| **발**(발측 구조 + 로드 절반 + 발측 볼조인트 + 안분한 나사·베어링) | **1.211** |
| **정강이**(크랭크·로드엔드 + 로드 절반 + RS03×2) | **2.608** |

→ 발 질량은 RL 심 모델(1.083 kg) 대비 **+11.8 %**에 그치고, **정강이가 +84 %** 로 뛴다.
2-RSU가 발목 모터를 근위에 올려 발끝 관성을 낮춘다는 설계 의도 그대로다
([[37_ankle_linkage_fidelity]]).

⚠**노트에 이 행을 "발"로 쓰면 안 된다.** `Ankle2Feet`는 정강이·로드·발에 걸친 기구다.
가능하면 표를 **강체 기준**(발 / 정강이)으로 재편하거나, 최소한 그룹임을 명기할 것.
→ [[81_rl_model_vs_cad_mass]] §3.

### 무릎 RS04는 표대로 정강이가 맞다

같은 검사를 무릎에 적용하면 표의 귀속이 **기하학적으로 타당**하다:
정강이 요크의 두 최대 솔리드가 무릎 축(−310)을 **감싸고**(COM −329.2 · −336.8, x = −160.2 /
−87.0 = 좌우 포크), 대퇴 구조는 z = −235.5에서 끝난다. 발목 모터와 달리 옮길 근거가 없다.

## §5 확인요청 — 명칭

| 표기 | 추정 | 근거 |
|---|---|---|
| `PipRoll2Yaw` | `HipRoll2Yaw` 오타 | 계보상 HipPitch2Roll 다음 |
| `Wlbow2WaistYaw` | `Elbow2WristYaw`? | 팔 계열인데 "Waist"가 들어감 |
| `WaistYaw2Pitch`의 `RS00 - Elbow_Yaw` | `Wrist_Yaw`? | 허리 링크에 팔꿈치 모터 |
| `Ankle2Feet`의 `RS03 - Ankle_A (1)` | `Ankle_B` | 같은 이름 2개 |
| CenterParts `RS04 - Hip_R` 축 = x(좌우) / HipPitch2Roll `RS04 - Hip_P` 축 = y(전후) | 두 이름이 서로 바뀐 것으로 보임 | 무릎·발목 피치축이 모두 x. 피치는 좌우축 회전 |

⚠ 마지막 항은 내 STEP 축검출 결과이므로 CAD에서 직접 확인 필요.

## §6 캠페인 CAD와의 독립 대조 — 같은 어셈블리다

| 캠페인 링크 | 사용자 링크 | Al(캠페인) | Al(표) | 차이 | 나사 개수 |
|---|---|---|---|---|---|
| L6_pelvis | CenterParts | 0.848 | 1.111 | **+31.0 %** | 69 = 69 ✅ |
| L5_hip_pitchroll | HipPitch2Roll | 0.654 | 0.582 | −11.0 % | 48 = 48 ✅ |
| L4_hip_yaw | PipRoll2Yaw | 0.563 | 0.505 | −10.3 % | 30 = 30 ✅ |
| L3_thigh | HipYaw2Knee | 1.320 | 1.270 | −3.8 % | 42 vs 72 |
| L2_shin | Knee2Ankle | 0.855 | **0.854** | **−0.2 %** | 0 vs 64 |
| L1_ankle_foot | Ankle2Feet | 1.536 | 1.643 | +7.0 % | 0 vs 47 |

**나사 개수가 세 링크에서 정확히 일치**(69·48·30)하고 `L2_shin`은 알루미늄 질량이 0.2 %
이내로 맞는다 → 두 데이터는 **같은 CAD 어셈블리**다. 나사 개수가 어긋나는 L3·L2·L1은
캠페인용 STEP 내보내기에서 체결구가 빠진 것이다(FEA는 체결구를 강체로 다루지 않음).

⚠**L6_pelvis +31 %** 는 별개 문제다 — 캠페인 STEP의 L6에 알루미늄 솔리드 약 97 cm³가
빠져 있다는 뜻이므로, L6 FEA 지오메트리가 최신인지 확인해야 한다.

## §7 노트 확정 전 체크리스트

1. ★ 총질량 표기를 **"편측+중앙 31.02 / 좌우 완성 ≈ 51.96 kg"** 로 수정
2. ★ **RS00·RS02 질량속성** 출처 확인 (목·WaistYaw2Pitch가 −2.9 kg 규모로 바뀜)
3. ★ **Ankle2Feet 행을 강체 기준으로 재편** — 이 그룹은 기구 전체다(발 1.211 / 정강이 2.608)
4. 명칭 정리(§5)
5. L6_pelvis 알루미늄 +31 % 차이 원인 확인
