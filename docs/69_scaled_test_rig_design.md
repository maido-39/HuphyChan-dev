# 69. 스케일다운 단일-다리 테스트 rig 설계 (걷기·호핑, RS02+RS00)

> 걷기·호핑 검증용 **한 다리** 테스트 셋업. 모터 **hip RPY + knee → RS02, ankle pitch/roll → RS00**. 우리 실측(51.5kg 전체로봇 걷기)에서 **기하 상사(geometric scaling)** 로 축소해 각 관절 토크가 모터 예산에 들도록 스케일 s를 정하고, 링크 치수·질량 타겟을 도출한다. 하중 원천: flat 앵커 [[2026-07-13_gen21_bent_p2]] gen21p2_fc. 모터스펙 [[reference-robstride-motor-specs]].

## 0. 모터 배치 & 스펙
| 모터       | peak / rated (Nm) | 담당 관절                                      |
| -------- | ----------------- | ------------------------------------------ |
| **RS02** | 20 / 7            | hip_pitch · hip_roll · hip_yaw · knee (×4) |
| **RS00** | 14 / 5            | ankle_pitch · ankle_roll (×2)              |

## 1. 우리 로봇 걷기 관절 토크 (51.5kg, gen21p2_fc)
| 관절 | RMS(열) | **P99(순시)** |
|---|---|---|
| **knee** | 45.5 | **112.4 Nm** ← 지배 |
| hip_pitch | 27.7 | 91.7 |
| hip_roll | 23.6 | 58.1 |
| ankle_pitch | 13.6 | 54.7 |
| hip_yaw | 12.8 | 32.9 |
| ankle_roll | 2.9 | 10.3 |
- 다리 세그먼트(원본): thigh(hip→knee) **451mm** · shank(knee→ankle) **400mm** · 다리전장 **846mm**. 한 다리 질량 **11.6kg**(thigh 5.10 · shank 2.82 · hip_roll 1.74 · hip_pitch 0.97 · foot 0.97).
- 호핑은 우리 데이터에 없음 → GRF 걷기 1.3BW→호핑 2.5~3BW 근거로 **~1.9× 추정**(검증 필요).

## 2. 스케일 법칙 & 안전 스케일
기하 상사 축소비 s: **길이 ∝ s · 질량 ∝ s³ · 관절토크 ∝ s⁴**(중력토크 = 질량×g×레버). 지배 관절 = **knee**(112/RS02 20 = 5.6배 > ankle_pitch 55/RS00 14 = 3.9배).

### 안전기준별 필요 스케일 (knee가 RS02 지배)
| 안전 기준 | 필요 s |
|---|---|
| 걷기만, SF 1.25 | ≤ 0.614 |
| 걷기+호핑1.9×, SF 없음 | ≤ 0.553 |
| **걷기+호핑1.9×, SF 1.25** | **≤ 0.523** |
| 걷기+호핑2.5×(보수), SF 1.25 | ≤ 0.488 |
| 걷기+호핑2.5×, SF 1.5 | ≤ 0.467 |
- s별 knee 호핑peak: 0.55→19.5(98% peak, **SF 여유 없음**) · **0.50→13.3(67%, ×SF1.25=16.7<20 ✓)** · 0.48→11.3(57%) · 0.45→8.8(44%).

## 3. ★권장 설계 — s = 0.50 (안전: 호핑 SF 1.25 커버)
> s=0.55는 호핑서 knee 98% peak라 SF 여유 없음 → **안전값 s=0.50 채택**. 호핑이 2.5×로 공격적이거나 추가 보수성 원하면 0.45~0.48.

| 관절 | 모터 | 걷기P99 | /peak | 걷기RMS | /rated | 호핑1.9×(×SF1.25) |
|---|---|---|---|---|---|---|
| knee | RS02 | 7.0 | 35% | 2.8 | 40% | 13.3 (16.7/20) ✓ |
| hip_pitch | RS02 | 5.7 | 29% | 1.7 | 25% | 10.9 (13.6/20) ✓ |
| hip_roll | RS02 | 3.6 | 18% | 1.5 | 21% | 6.9 (8.6/20) ✓ |
| hip_yaw | RS02 | 2.1 | 10% | 0.8 | 11% | 3.9 (4.9/20) ✓ |
| ankle_pitch | RS00 | 3.4 | 24% | 0.9 | 17% | 6.5 (8.1/14) ✓ |
| ankle_roll | RS00 | 0.6 | 5% | 0.2 | 4% | 1.2 (1.5/14) ✓ |

**전 관절 걷기 5~35%·호핑+SF 전부 여유** (knee 16.7/20 최빡).

### 링크 치수 (원본 × 0.50, 회전중심↔회전중심)
| 세그먼트 | 길이 |
|---|---|
| thigh (hip→knee) | **226 mm** |
| shank (knee→ankle) | **200 mm** |
| 다리 전장 (hip축→발) | **~423 mm** |

### 링크 질량 타겟 (구조물, ×s³=0.125 · 모터질량 별도)
| 링크 | 구조 질량 |
|---|---|
| thigh | **640 g** |
| shank | **350 g** |
| hip_roll 하우징 | 220 g |
| hip_pitch 하우징 | 120 g |
| foot | 120 g |
| **구조 합** | **~1.45 kg** |

→ + 모터(RS02×4 ≈2.0kg + RS00×2 ≈0.5kg) ≈ **다리 총 ~4.0 kg**

## 4. 스케일 대안
- **s=0.55** (걷기~50%·호핑 SF없음): thigh 248·shank 220·다리 465mm·총 4.4kg — 호핑 마진 빠듯.
- **s=0.62** (걷기 전용 최대): thigh 280·shank 248·다리 525mm·총 5.3kg — 걷기 OK but 호핑 시 knee 31.6·ankle 15.4 전부 초과 ⚠.
- **s=0.45** (보수, 호핑 2.5× 대비): thigh 203·shank 180·다리 381mm — 전관절 큰 여유.

## 4b. 세그먼트 비율 (thigh:shank)
- 우리 로봇 = **1.13:1** (451:400). 우리 토크 데이터가 이 비율 기준 → rig도 1.13:1(226:200) 유지 시 **데이터 직결**.
- 인간 이상비 = **≈1:1** (Winter/Dempster 관절중심 세그먼트, 허벅지·종아리 둘 다 ~0.245×키; 뼈 crural index로는 대퇴골이 김 1.2:1이나 기구엔 관절중심이 맞음). 1:1 원하면 **thigh≈shank≈213mm**, 단 하중 ~5~10% 재이동(근사 적용).

## 4c. 발목 A/B 링키지 로드엔드 베어링
2-RSU식 A/B 모터→발목 로드의 로드엔드: **로드력 = 발목토크 / 모멘트암**. ankle_pitch 지배.
| | 걷기 | 호핑×SF |
|---|---|---|
| rig s0.50, arm 20mm | 171 N | 406 N |
| rig s0.50, arm 25mm | 137 N | 325 N |
| rig s0.50, arm 30mm | 114 N | 271 N |
| (실기 참고, arm 60mm) | 912 N | 2165 N |
- **3mm 로드엔드 통상 동적 ~0.4~1.0kN·정적 ~0.8~2kN(제품편차 큼)**.
- **rig(s0.50)이면 3mm 조건부 충분**: arm ≥25mm·동적정격 ≥500N. 단 확인 필수 — ① 구체 datasheet 정격, ② **모터 스톨 최악**(RS00 14Nm/arm25mm=560N), ③ **로드 좌굴**(압축, 로드 길이/직경 Euler), ④ **로드엔드 스윙각(~±10~15°) vs 발목 ROM**.
- **실기(51.5kg)면 3mm 불가** — 걷기 912N·호핑 2165N → **6~8mm 로드엔드**(2~4kN) 필요.
- 모멘트암 클수록 로드력↓ → 가능한 크게(≥25~30mm).

## 4d. 단일 다리 CoM / 마운트
- CoM은 "정중앙"보다 **지지축(레일/붐) & 발 접지선에 정렬**이 목적(리그 안정·베어링 하중, 바이패드 밸런스 아님).
- **수직 레일 호퍼**: 이동조립체 CoM = 레일축 = 발 위 일직선(collinear) → 가이드 베어링 모멘트 회피. **중립자세서 발 위로** 정렬, 무거운 hip 모터를 마운트축 대칭 배치.
- **원형 붐(걷기)**: 붐이 측방·yaw 반력 → CoM 횡정렬 덜 critical.
- **시상면 3-DoF(hip_pitch·knee·ankle_pitch)만** 쓰면 CoM이 시상면 내 → 가장 단순(hip_roll/yaw 잠금).
- 붐/캐리지 관성은 유효부하에 **별도 가산**.

## 5. 주의사항
1. **지배 = knee(RS02)**. hip_roll/yaw·ankle은 큰 여유 → 스케일은 knee가 결정. **호핑 목표면 s=0.50(권장, SF커버)**, 걷기만이면 s ≤ 0.62.
2. **호핑 1.9×는 추정** — 실 호핑 GRF로 재검증 권장. 공격적(2.5×)이면 s=0.45~0.48로 보수화.
3. **모터질량 불변**(스케일 안 됨) → 소형 rig서 질량 지배. 구조 링크는 160~850g로 매우 가벼움(CNC 알루미늄/카본, 또는 프린트+금속 조인트로 충분).
4. **열(RMS) 여유**: knee 걷기 RMS 4.2 < RS02 rated 7 (59%) → 연속운전 OK. 호핑 반복 시 duty 재확인.
5. **단일 다리 = 가이드 필수**: 호핑은 수직 레일(planarize), 걷기는 원형 붐이 표준. **붐/캐리지 관성이 유효부하에 가산**되니 위 질량예산에 별도 포함.
6. 값은 s의 함수 — 다른 스케일·DoF 구성(예: 시상면 3-DoF hip_pitch·knee·ankle_pitch만)으로 재계산 가능. 호핑 하중을 정확히 보려면 **우리 정책에 호핑 태스크 학습 후 실측**이 최선.
