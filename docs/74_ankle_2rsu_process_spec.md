# 74. Ankle 2-RSU 최적화 — 전 프로세스 재정리 (canonical, 2026-08-13)

> 사용자 지시: "목적을 잃었을 수 있으니 전 프로세스 재정리 — ①데이터는 지금까지 해석 데이터 전부 ②파라미터 고정값/최적화 범위 재정리 ③목적함수 재모델링." 본 문서가 **단일 기준(canonical)** — docs/71(이력)·72(rev3)·73(문헌)은 근거 문서로 강등. 모순 시 본 문서가 우선.

## §1 목적 (한 문단)

측정된 보행 부하(13개 학습 정책의 발목 관절 토크·속도·자세 시계열)를 2-RSU 기구로 리플레이했을 때, **JS6 로드엔드(±20°)·RS03×2·현행 ROM으로 성립하면서 P99 부하 마진이 최대가 되는 기구 치수 9개**를 확정한다. 산출물 = CAD로 넘길 치수 세트 + 각 부품 하중 설계값.

## §2 조인트·기구 모델 (2026-08-13 사용자 확정)

- **발측 JS6**: 발 측면에 볼트 **Y축(발 좌우)** 고정. Y축 회전 **무한**(pitch 추종 자유), 요동은 **Y축 기준 20° 원뿔**(아이축 e가 Y의 20° 원뿔 내). 로드 u⊥e이므로 성립조건 = **arcsin(|u·ŷ_foot|) ≤ 20°** (로드의 좌우 기울기만 제한). ⚠이력: 수직(+Z) 원뿔로 잘못 모델링했던 §13~§14의 "ROM 축소·재학습 필수" 결론은 철회됨(§71-15).
- **크랭크측 JS6**: 볼트 = 크랭크 핀축(월드 X) → arcsin(|u_x|) ≤ 20°.
- **트위스트 적합성**: 한 로드의 양단 아이축을 로드 스핀 1자유도로 동시 만족 — 양단 볼트축 투영 상대각 Δψ(자세 함수)가 결합 여유((20−요동)_상단+(20−요동)_하단) 안에 들 것. 현 승자 기하 여유 +11~19° OK.
- **기구학**: 폐형 IK φ=β±acos(k/ρ), 분기는 φ0 타깃(0/180) 최근접+연속성, Jacobian 유한차분(각도랩), 가상일 τ_m=J⁻ᵀτ_j. 좌표: x=좌우, y=앞뒤(앵커 +y), z=위. R=R_pitch@R_roll (docs/71 §10a FK 검증).

## §5 목적함수 (재모델링 — 사전식 · Deb 3규칙)

**절대 규칙**: hard 제약과 목적을 혼합(가중 페널티)하지 않는다. infeasible끼리는 위반량 합(등급형)으로만 비교. best-feasible-ever 유지.

```
T0 (hard, 전부 만족해야 feasible):
  H1 폐합:      IK 해 존재 ∧ |det J|>1e-9 ∧ 전달팔>0 — WS 그리드(내부 19×13, 최종 41×21+코너) + 수요샘플 100%
  H2 요동각:    max_WS arcsin|u·ŷ_foot| ≤ 20 (발측) ∧ max_WS arcsin|u_x| ≤ 20 (크랭크측) ∧ 트위스트 Δψ ⊂ 결합여유
  H3 모터토크:  max_g P99_g(|τ_m|) × 1.25 ≤ 60      (g ∈ flat/rough × fc/fcp 4그룹)
  H4 T-N:       max_g P99_g(util) ≤ 1, util=|τ|/lim(|ω|), 모터링 사분면(τω>0)만
  H5 로드력:    max_g P99_g(|F_rod|) × 1.25 × 1.5 ≤ C0 (측별: 크랭크측 JS6 카탈로그 확정 필요·발측 GE급)
  H6 전달비:    min_WS(팔/r) ≥ 0.45 (스톨 유도: 60·s0/(C0·A_r))
  H7 간섭:      로드–정강이/로드–로드/크랭크–발등 클리어런스 > 0 (캡슐 근사) [구현 예정]
  H8 물리성립:  RP_h 스택·짐벌 요크 ROM ⊇ 관절 ROM·스토퍼 패드 경로 확보 [CAD 게이트]
                (스토퍼 **하중·단면 요구는 정량 종결** — docs/78 §13: 롤 짐벌 반경 ≥60 mm·
                 전단 ≥86 mm², 크랭크측 경로는 로드엔드 s0 0.54로 **금지**. CAD는 경로 확보만 판정)
T1 (피크, best-effort): peakScore = min(0, min{1−peak(|τ_m|)/60, 1−peak(util), 1−peak(F)/C0}) 최대화
    — NOCLIP 필터 적용, 동률 허용오차 5pp(피크 CI ±4~47%), 초과분 보상 없음(min(0,·))
T2 (주 목적): p99Score = min(정규화 마진 전체) 최대화 — "통과"가 아니라 마진 최대화
    마진 = {1−P99util류(H3~H5 각각), 1−요동/20(발측·크랭크측), (전달비−0.45)/0.55}
T3 (동률): 로드력 RMS ↓ (마모) → 크랭크 스윕부피 ↓ (패키징)
```

**옵티마이저**: DE/rand/1/bin(NP 120, F 0.6, CR 0.9) + Sobol 초기화, 시드 ≥3(freeze 100), 정체 이중 조기종료, 게이트 위반은 등급형. φ0 ∈ {0,180} 이산 + 분기 연속성 assert. 구현: `analysis/ankle_opt_de_v7_romscan.py`(H7·H8·트위스트 hard화는 freeze판에서 추가).
