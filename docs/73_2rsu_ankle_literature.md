# 73. 2-RSU 발목 문헌 딥리서치 (2026-08-13, 101-agent workflow wl5an46fs)

> 질문 5개(Q1 실기 발측 체결 / Q2 S vs U 위상 / Q3 요동각 제약 합성기법 / Q4 광각 부품 상한 / Q5 대안 위상). 검증 3표 적대투표 통과분만 수록(11건, 전부 3-0). 원문·증거: 워크플로 저널 `subagents/workflows/wf_5390183f-37a/journal.jsonl`.
> **주의(2026-08-13 사용자 결정)**: 본 리서치의 "발측 U 전환" 권고는 **기각됨** — JS6(±20°·수직) 하드 확정. 문헌은 선례·제약 근거로만 사용. 설계 방향은 [[72_ankle_2rsu_objective_spec_and_direction]].

## 핵심 결론 (요약)

문헌의 답은 "부품이 아니라 위상": 46~61° 요동 수요를 구면 부품으로 푼 검증된 선례는 없음. 상용 광각 구면베어링 상한 = **FK HIN-T 18~24°**(사이즈별; HIN8T/10T=20°) — **JS6급 20°는 사실상 카탈로그 천장**. 우리가 택한 "베어링 원뿔이 ROM을 캡"하는 경로의 실기 선례 존재(MIT 의족).

## Q2 — 정통 RSU 위상 (Cervettini et al., IIT, IEEE Humanoids 2025, arXiv:2509.16469)

- 다리 체인 = R(정강이 크랭크, 구동)→**S(크랭크 팁)**→**U(발 체결)**. 구면조인트는 요동 수요가 작은 크랭크측(우리 실측 1.5~4.2°)에, 발측은 U블록. [3-0]
- 발목 본체 = 수동 U0 짐벌(pitch-roll) — 우리 구조와 동일. DOF 부기: R1+S3+U2=6/다리, 로드 스핀 잉여자유도 소멸. [3-0]
- 단, 이 논문은 원뿔한계를 **분석한 게 아니라 회피**: 요동각·미스얼라인 모델 전무(제약=액추에이터 정격·충돌·IK존재성만). U 선택의 백래시/마모/패키징 트레이드 보고 없음. [3-0]

## Q3 — 요동각 제약의 합성기법 선례 (우리 v6 구조 방증)

- **Rao & Rao 2009** (MMT 44:477, 3-RPS): 구면조인트 허용 ROM을 **규정 제약**으로 놓고 치수 합성. [3-0]
- **Kumar et al. 2022** (MMT 173:104796, DFKI/RH5 그룹, 2UPS-1U 발목 모듈): 플랫폼측 구면조인트 **±30°(π/6) 명시 제약**(Table 3)으로 최적화 — 요동한계를 1급 hard 제약으로 다루는 우리 방식과 동일 패턴. [3-0]
- **Cervettini 2025**: 제약을 재매개변수화로 **소거**(크랭크 c(γ)=c_min/(1−γ), 로드 r(δ)를 IK 존재조건 |k/ρ|≤1 유도 범위로 보간 → 모든 파라미터가 자동 feasible). 페널티 아님. [3-0]
- **Merlet & Daney 2005** (ICRA): 구간해석으로 **인증된 설계 박스**(제조오차에 강건) 반환. [3-0]
- 공통점: 전부 hard-제약 우선/소거 — 소프트 페널티 합성 없음(우리 Deb 독트린과 일치).

## Q1/Q5 — 실기 선례

- **RH5** (DFKI 62.5kg): 2SPRR+1U — 발측 체결이 R-R 쌍(구면 없음). ROM pitch −51.5~+45 / roll ±57, 토크 121~304 N·m, 발목 3.6kg — 발측 구면 회피 위상이 성능 손실 없음을 실증. [3-0]
- **MIT 동력 의족** (Hsieh et al., Biomimetics 2024, Herr lab): RR-2RSS — 로드가 발목측 **구면 스위블 베어링으로 종단**되는 실기. 그 베어링의 **27° 원뿔이 기구 ROM을 캡** — "베어링 요동한계가 ROM을 정의"하는 우리 JS6 경로의 직접 선례. [3-0, 인과 강화판은 1-2 기각]
- 상용 휴머노이드(G1/H1/Optimus/Figure 등) 발측 체결 부품의 티어다운 데이터는 **검증 생존 실패 — 미확인 공백**. [–]

## Q4 — 광각 부품 천장

- FK HIN-T 고미스얼라인 시리즈: HIN4T(1/4") 24° / HIN6T 23° / **HIN8T·HIN10T 20°** / HIN12T 18°. 카탈로그 구면 최광각이 20° 내외 = **JS6±20 가정은 부품 현실과 정합, 그 이상은 존재하지 않음**(자동차 볼조인트류 포함 검증 생존분 없음). [3-0]

## 우리 설계에의 적용 (JS6 확정 후)

1. 요동한계 = 1급 hard 제약(Kumar/Rao 선례) → v6 T0 유지. ✅
2. ROM을 베어링 원뿔에 맞춰 캡(MIT 의족 선례) → ROM 공동설계 + 재학습 = docs/72 §3 경로. ✅
3. IK 존재조건 재매개변수화(Cervettini)는 v6 개선 후보(로드길이 박스를 유도 범위로 좁혀 DE 낭비 제거).
4. 크랭크측 S 요동 1.5~4.2° ≪ 20° — 문헌 위상과 우리 측정이 서로 확인. ✅
