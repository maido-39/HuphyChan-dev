## §4 판정의 핵심 — 평가기 32 ep × 4 시나리오

**절대 단일 롤아웃으로 판정하지 않는다**(`eval_raw_stats.py` docstring, 08-26 세션에서 7회 뒤집힘).
전 시나리오 **32 에피소드 × 20 s**(warmup 2 s 제외 18 s), 시나리오당 별도 호출·`max_parallel_envs=8`
(32 병렬은 RSS 13.6 GB로 스왑을 유발한 적 있음 — 이번 최대 RSS **6.4 GB**).
**교란은 양쪽 동일하게 전부 ON**(DR·관측노이즈·푸시 = 평가기 기본값).

### 4d. ★200 Hz 다중 env 프로브 — 50 Hz의 +21 %는 에일리어싱이 아니었다

50 Hz 평가기의 하중률은 착지 스파이크(폭 15–25 ms)를 에일리어싱하므로 단독 판정 근거가 못 된다
([[2026-08-27_bundleE1_AB]] §4). `impact_probe_multi.py`(ContactSensor를 `sim.step` 훅 안에서 읽어
**물리 서브스텝 전량** 샘플링, 24 env × 1.6 m/s)로 다시 쟀다.

**먼저 계측 출처를 검증했다**(하중 기준 출처검증 규칙 — 데이터 세대 점검):
프로브 스크립트가 D1 기준값 기록(08-26 16:08) **이후인 08-27 15:01에 수정**됐다(`47bae97`).
변경 내용은 **BW를 모델에서 유도**하도록 한 것뿐이고, 이 v3 모델(35.347 kg)에서는 정확히
**346.8 N = 옛 하드코딩 값**이라 검출 로직·수치 모두 비교 가능하다. 그래도 가정하지 않고
**D1을 오늘 코드로 재측정**했고, 두 arm 모두 **2회씩 반복**해 런간 산포를 함께 쟀다.

⇒ **D1 ≈ 20.6 BW/s(산포 ±5 %) vs P1 ≈ 46–58 BW/s(산포 ±12 %) = 2.2–2.8배.**
아카이브 D1 값이 오늘 재측정과 일치하므로 **코드 세대 차이가 아니라 실재하는 차이**다.
판정 기준(플래너 지정: 25 % 이내면 에일리어싱, **1.5배 초과면 loud**)에서 **명백히 loud 구간**이다.

**무엇이 나빠지고 무엇이 안 나빠졌나** — 구분이 중요하다:
- **피크 GRF는 무변화**(1.213–1.224 → 1.217–1.253 BW). 최대 힘은 그대로다.
- **착지 빈도도 무변화**(2.19–2.20 → 2.20–2.22/s). "더 자주 밟아서"가 아니다.
- **상승률만 나빠졌다**: 중앙값 2.2–2.8배, p90 64 → 104–110(**+63 %**), p25 14.1 → 18.2(+29 %).
  즉 **같은 크기의 힘을 더 급하게 싣는다** = 발이 더 딱딱하게 닿는다.

**메커니즘**: cmd 1.6에서는 `stand_still_penalty`가 양 arm 모두 동일하게 동작한다(1.6 > 0.3 > 0.05).
즉 **1.6 m/s의 보상 함수는 두 arm이 완전히 같다.** 그런데도 착지 스타일이 바뀌었다는 것은,
0.05–0.3 대역에서 들어온 800 iter분의 그래디언트가 **같은 신경망을 공유하는 전 속도대의 착지 정책을
끌고 갔다**는 뜻이다. 저속 대역이 전체 명령의 2–8 %에 불과한데도 그렇다([[2026-08-27_low_speed_command_research]] §1d).

|---|---:|---|---|---:|
| **bundleD1_AB** | **21.0** | | bundleV4_AB | 42.2 |
| bundleTRT_AB | 23.7 | | **bundleP1_AB** | **46–58** |
| bundleB2_AB | 28.6 | | bundleE1_AB | 54.1 |
| bundleC3_AB | 41.4 | | bundleD1_RP | 64.5 |
| | | | bundleC5_AB | 69.7 |
| | | | bundleCTL_RP | 81.5 |

**두 가지 읽기가 다 사실이다**:
1. P1은 **자기 대조군 대비 2.2–2.8배 나쁘다**. 이건 부인할 수 없다.
2. 동시에 P1은 **형제 arm 모집단에서 중간값**이다(C3 41.4·V4 42.2와 E1 54.1 사이).
   **D1(21.0)·TRT(23.7)·B2(28.6)가 예외적으로 낮은 그룹**이고, D1이 확정 레시피가 된 이유 중
   하나가 바로 그 최저 하중률이었다([[2026-08-26_bundleD1_AB]] §3c). 즉 P1은 "특별히 나쁜 정책"이
   아니라 **D1이 우연히 잡고 있던 특별히 좋은 착지를 잃은 것**에 가깝다.

⚠ 미확인: 이 하중률 악화가 **deadband 자체의 필연**인지, 아니면 +800 iter 재학습의 **시드 수준 변동**인지
구분하지 못했다. 구분하려면 같은 deadband로 시드를 바꿔 2–3개 arm을 더 돌려야 한다(각 40분).

## §5 판정 — 저속은 **해결**, 그러나 **조건부**(착지 충격과의 맞교환), P2는 **불필요**

1. **문제 대역만 정확히 고쳐졌다.** 0.25에서 +128 %, 0.5·1.6은 변화 없음(±3 % 이내).
   연구노트 §1b가 예측한 그대로다 — 0.05–0.3 대역만 게이트가 새로 켜지므로 그 위 속도는 손댈 이유가 없다.
2. **정지가 지켜졌다.** deadband 0.3이 막고 있던 실패모드(cmd 0에서 영구 스텝핑)가 재발하지 않았다.
   0.05는 원래 코드베이스가 7곳에서 쓰던 표준값이라 예상된 결과지만, **가정하지 않고 측정했다**.
3. **비용은 보상 −5.02 한 줄뿐**이고 그건 새 벌점 자체다. 낙상 0, ep 길이 만점, 추종 무변화.
4. 연구노트 §5의 권장 순서는 "P1 단독 → 안 풀리면 P2(air_time 0.5 → 0.05)"였다.
   **P1이 풀었으므로 P2는 보류**한다. P2는 [[2026-07-05_periodic_contact_removal]]이 **의도적으로**
   정지 친화적으로 잡은 값을 되돌리는 것이라 헛디딤 게이밍 위험을 안는데, 그 위험을 살 이유가 사라졌다.
5. 남은 미측정: **측면(E)·후진(S)·회전 저속**은 안 봤다. 이번 격자는 전진(N) 4점뿐이다.
   deadband는 `cmd_mag`(방향 무관)과 `wz_mag`에 동시에 걸리므로 방향 대칭성은 구조적으로 기대되지만
   **측정된 바 없다** — V2 본학습 전에 fc 121-command 격자로 확인할 것.

6. ★**그러나 무조건 채택은 아니다**(§4d). 200 Hz 실측 하중률이 D1의 **2.2–2.8배**다.
   피크 힘과 착지 빈도는 그대로이므로 "더 세게/더 자주"가 아니라 **"더 급하게" 싣는 것**이고,
   이 프로젝트의 목적이 **하드웨어 하중 측정**이라는 점에서 하중률은 무시할 수 있는 축이 아니다
   (베어링·감속기 충격 수명은 피크보다 상승률에 민감하다). [[2026-08-27_bundleE1_AB]]는 **같은 지표가
   2.6배 나빠졌다는 이유로 기각**됐으므로, 여기서만 넘어가면 일관성이 없다.

⇒ **판정: 저속 수정 자체는 유효하고 메커니즘도 확인됐다. 그러나 V2 본학습 스택에 무수정 투입은
   플래너 결정 사항이다.** 선택지는 세 가지이고, 필요한 추가 측정도 각각 다르다:

| 안 | 내용 | 비용 |
|---|---|---|
| **A. 그대로 채택** | 저속 순응을 사고 하중률 2.2–2.8배를 받아들인다. P1은 형제 arm 모집단의 중간값이지 이상치가 아니다(§4d) | 0 — 단, 사이징 하중 근거를 P1 기준으로 재산출해야 함 |
| **B. 원인 분리 먼저** | 같은 deadband로 시드만 바꿔 2–3 arm 추가 → 하중률 악화가 deadband의 필연인지 재학습 변동인지 확정 | arm당 40분 + 프로브 1분 |
| **C. 착지항으로 상쇄** | P1 + `foot_impact_velocity` 가중치 복원(`half` → 원래값) 또는 §4d의 상승률을 **200 Hz에서** 벌하는 항. ★E1의 교훈상 **50 Hz `foot_loading_rate`는 쓰면 안 된다**(측정 회피를 학습함) | 40분 + 새 항이면 reward research 선행 |

**추천은 B → C 순서**다. A는 "D1이 잡고 있던 최저 하중률"이라는 확정 레시피의 핵심 근거를
말없이 포기하는 것이라, 근거를 남기지 않고 하면 나중에 사이징에서 되물린다.
