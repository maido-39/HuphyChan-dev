착지 번들의 16384 env 재시험 세 arm 중 하나. c3 AB `model_31999` warm-start, +800 iter 목표.
- 변인: `PYG_INIT_MID=1` + `PYG_BASE_HEIGHT_ANCHOR=1`(w −5) + `PYG_SOFT_LANDING_MODE=both`
- run dir: `logs/rsl_rl/pygmalion_velocity/2026-08-26_12-10-40_bundleC2_AB`, 12:10 시작

## §2 왜 중단했나 — **의도적 중단, 실패 아님**
같은 조합을 1024 env로 먼저 돌린 `bundleB2_AB`가 **12:40에 명확히 기각**됐다:
duty 0.57 → **0.75**, stride/s 1.40 → **0.83**, 추종 오차 **0.524**(거의 못 걷는 수준).
원인은 하중률 항의 "발을 바닥에 붙여두면 dF/dt = 0" 해킹 경로다([[2026-08-26_bundleB2_AB]] §4).

C2는 **같은 조합**이므로 큰 배치에서 같은 실패를 반복할 뿐이고, 그 GPU 슬롯이 더 가치 있는 질문에 쓰인다:
**"앵커는 켜고 하중률은 끈"** 빠진 칸. 그래서 iter 32345에서 중단하고 그 자리에 [[2026-08-26_bundleC4_AB]]
(`PYG_INIT_MID` + `PYG_BASE_HEIGHT_ANCHOR` **w −15**, 하중률 없음)를 띄웠다.

- 중단 시점: iter 32345 / 32799 (체크포인트는 남아 있음)
- 와치독 spec은 `enabled=False`로 내려 자동 resume을 막았다
