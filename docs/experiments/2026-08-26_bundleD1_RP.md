## §1 무엇을 시험했나
[[103_v2_training_plan]] §4a에서 AB로 확정한 레시피가 **발목 기구가 바뀌어도 유효한가**.
`PYG_SOFT_LANDING_MODE=half`는 AB 시험에서 실제로 검증된 설정(= `foot_impact_velocity` 가중치 ½)이다.
하중률 항은 부호 버그로 죽어 있었으므로 여기에도 넣지 않았다([[2026-08-26_human_landing_bundle]] §12).

## §4 왜 AB만큼 극적이지 않은가 — **고칠 병리가 없었다**
| 200 Hz, DR off | CTL_AB → D1_AB | CTL_RP → D1_RP |
|---|---|---|
| 피크 GRF (BW) | 2.353 → **1.224** (−48 %) | 1.248 → 1.253 (**변화 없음**) |
| 하중률 (BW/s) | 277.4 → **21.0** (−92 %) | 81.5 → **64.5** (−21 %) |
| 입각 무릎 | 51.4° → 39.1° (−12.3°) | 45.9° → 39.9° (−5.9°) |
| 낙상 (DR on) | **12 → 0** | 0 → 0 |

**RP 대조군은 이미 AB 처치군 수준으로 부드럽게 착지하고 있었다**(피크 1.248 vs AB 처치 후 1.224).
초기자세 변경이 AB에서 −48 %를 만든 것은 AB 대조군이 **비정상적으로 딱딱했기** 때문이고,
그 딱딱함은 초기자세와 폐루프 발목의 결합에서 나온다([[2026-08-26_bundleCTL_RP]] §4).
RP에서는 남은 개선분이 **하중률 −21 %와 자세 −5.9°**뿐이고, 이는 무릎 신전항의 몫으로 보인다.

⇒ **레시피는 두 arm 모두에서 유효**하지만, **효과 크기는 기구에 의존한다**. V2 계획에는 두 arm 공통으로 넣되,
"초기자세가 −48 % 충격 감소를 준다"는 표현은 **AB 한정**으로 좁혀 적어야 한다.
