## §4 AB와의 대조 — 이식이 성립하는가
| | AB(D1 vs CTL) | **RP(D1_RP vs CTL_RP)** |
|---|---|---|
| 입각 무릎 | 51.1° → 40.1° | 45.9° → **39.9°** |
| 전진 오차 | 0.163 → 0.117 | 0.147 → **0.140** |
| 200 Hz 피크 | 2.353 → 1.222 BW | 1.248 → 1.253 BW |
| 200 Hz 하중률 | 277 → 69.7 BW/s | 81.5 → **64.5 BW/s** |

★**두 arm의 대조군이 다르다**: AB의 CTL은 200 Hz에서 2.353 BW·277 BW/s로 심하게 때려 박는데
RP의 CTL은 1.248 BW·81.5 BW/s로 이미 부드럽다. 즉 **초기자세의 이득 대부분은 AB에서 나왔고**,
RP는 애초에 그 병리가 약했다. 최종 자세(무릎 ~40°)는 양 arm이 수렴한다.
