# AB 발목 미사용 의혹 — 다각도 데이터 감사 (2026-08-28)

> *한 줄*: 사용자 의혹("AB 모드 발목 토크 0 = 안 쓰는 버그 아닌가")을 6각도로 검토. **버그 아님.**
> 토크 0은 폐루프 직접-축 컬럼의 구조적 0이고, 발목은 RP(직렬)와 ±10%로 동일하게 쓰인다.

## 방법
`analysis/out/ankleAB_c3_fc.npz`(폐루프) vs `ankleRP_c3_fc.npz`(직렬), 6각도 팬아웃 + 양방향 적대검증(9 에이전트).

## 판정
**버그 없음.** 직접 `tau_ankle_joint=0.00000`은 **0이어야 할 유일한 컬럼**(폐루프 구속 부기).
액션 드롭이면 관절이 0° 근처 정지해야 하나 발목은 full ROM(61–71°) 스윙. §7 수정(크랭크 사이징)이
이미 이 측정 아티팩트를 처리했고, 이번 감사가 **물리적으로 발목이 살아있음**을 5각도 독립 확인.

## 함의
- ★사이징: 발목 실토크는 tauank_eq ~20 N·m RMS / 75–79 N·m peak. 크랭크(RS03) RMS ~65%·peak ~95% 정격 사용 → 2-RSU 증폭이 실제로 필요함이 재확인.
- ★AB는 **upper-DOF 학습(v2u1)을 얹어도 되는 건전한 베이스**.
- AB≈RP 발목 사용량(±10–15%) → 두 발목 기구가 같은 물리를 낸다는 [[2026-08-26_ankleAB_vs_RP_comparison]] 결론과 정합.
