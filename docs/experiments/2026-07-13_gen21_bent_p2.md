## 4. 부모 비교 (gen21 P1 → P2 resume + 전 앵커 bentp2 대비)
**(a) P1→P2 (단일변인 = DR+push 램프, §1 실증)**:
- vy +1.0 65→**98%**·후진 $-2.0$ 69→**91%**(push-학습이 측방·후진 안정화 — bent 계보 선례 재현) · 2.5 85→**92%** · GRF P99 1.38→**1.31BW** · knee P99 102.5→112.4(+9.7%, DR-off 명목→배포급 하중 상승) · 낙상 0/0→0/0 유지 · knee $\omega$ P99.9 13.9→14.3.
