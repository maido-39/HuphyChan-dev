# 85. 단순 보행 조건 PLA 트리아지 — 무엇을 먼저 CNC로 바꿔야 하나

*v1 2026-08-20 · **v2 2026-08-20 (적대적 검증 13에이전트 반영 — 6개 주장 중 5 DISPUTED · 1 REFUTED.
순위는 전부 재현됐고, 원인 설명·횡모멘트 규약·발 하중 규약·수명 환산·"출력 가능 3종"을 정정)***

질문: 전 부품을 당장 CNC 가공할 수 없다. **평지 단순 보행**만 한다면 어느 파츠를 먼저
알루미늄으로 바꿔야 하고, 어느 것은 PLA 출력물로 당분간 버티나.

![PLA triage](img/pla_triage_walk.png)

> 막대 = 단순보행 하중에서의 부품별 체적가중 p99 응력, 검은 눈금 = 캠페인 설계기준
> (rough+push 포락). 색 = PLA 응력 밴드. 오른쪽 = 링크별 최악 부품의 캠페인 대비 비율.

## §1 답 — 단순 보행이어도 **여섯 링크의 판재는 전부 바꿔야 한다**. 순서만 정해진다

단순 보행(T2: vx −0.5~1.0 m/s, |vy|·|wz| ≤ 0.5)으로 하중을 낮춰도 부품 응력은 캠페인 기준의
**0.57~0.75배**다(§2). PLA 피로 허용 3.4 MPa는 주요 부품 응력(12~80 MPa)의 **1/4~1/23**.

**36개 실부품 중 RED 28 · ORANGE 8 · GREEN 0.** (메시 슬리버 20개 < 0.5 cm³ 제외)

★**그리고 판재보다 먼저 깨지는 것이 있다** — 2-RSU 발목의 푸시로드(PLA 좌굴 SF 0.14)·
크랭크(0.18)·십자 핀(0.77)·스토퍼 패드. 링크 FEA에 없는 부품들이라 별도 문서
[[86_internal_parts_pla_walking]]에 있다. **가공 1순위는 그쪽이다.**

| **L2 발목모터 레일 ×2** | 16+16 | 4.5 / 4.2 | 955~1390 h / 2~3 h | ★4×M4 탭 부재 + 크리프 |

★**v1은 "골반 상판·발목모터 레일 2개는 PLA로 미룰 수 있다"고 썼다. 철회한다.**
- **골반 상판(V5)은 L6 모델의 구속면이다** — 고정 절점 1,088개 중 529개가 이 판에 있고
  (`setup_L6_pelvis.json` fix_desc: "2020 보어 + 10볼트 링 + 측면 레일"), 캠페인 규칙
  (docs/78 §2, `bc_filter_mm` 4)은 구속 근방 응력을 설계값에서 **제외**한다. 4.8 MPa는 이 판의
  하중 응력이 아니라 경계 근방 값이다. 판정하려면 **구속을 힙 보어로 옮겨 재해석**해야 한다.
- **셋 다 탭 나사 체결부재다**(`bolts_all.json`): 상판은 앞·뒤판에서 오는 **M5 16본**의 탭
  부재(물림 12.98 mm)이자 Waist_Yaw RS04 **M4 10본**의 헤드 시트다. PLA 나사산 박리력
  0.6πD·L_e·τ(층간 9.8 MPa) = **1,200 N** vs 4.6급 M5 예압 2,215 N → **조이다가 벗겨진다**
  (SF 0.54). 헤드 지압 1,370 N / 25 mm² = 55 MPa > PLA 항복 51. 레일은 M4 4본씩의 탭 부재
  (물림 39.5 mm라 박리는 SF 2.1)지만 예압이 크리프로 풀린다(docs/79 §8e, docs/80 §4 "볼트 예압 금지").
- 레일의 "모터 체결" 플래그는 카탈로그 외형 프록시와의 **접선 접촉 4절점**이지 볼트 패드가
  아니다 — 레일은 마운트 블록에 붙는다. 열 조건은 그래서 덜 확실하지만, 위 두 이유로 무의미.

**결론: 이 해석으로 PLA 출력이 정당화되는 링크 부품은 없다.**

## §2 왜 하중을 낮춰도 안 되나 — v1의 "체중" 설명은 틀렸다

v1은 "수직력이 88~93 % 남아서"라고 썼다. 수직력 비율 자체는 맞지만(전박스 대비), **원인이 아니다**.
검증이 단위해를 성분별로 끄고 켜 확인한 결과:

| 링크 | 지배 성분 | 근거 |
|---|---|---|
| L1 발 | **Fz(GRF)** | 밑창판 76.7 중 71.7이 Fz |
| L2 정강이 | 수평력 Fx/Fy | |
| L3 대퇴 | **무릎 모터토크 Maxial** | |
| L4·L5·L6 | **횡모멘트 Mt1/Mt2** | L5 뒤 암 76 중 67.5가 Mt, Fz는 3.0 |

즉 판재 대부분은 **굽힘 모멘트와 모터 토크**로 응력이 난다. 그리고 **캠페인 기준 대비**로는
모든 성분이 비슷하게 떨어진다 — Fz 0.70~0.73, Fx 0.75~0.88, Fy 0.53~0.77, Mt 0.73~0.77,
Maxial 0.46~0.80. 어느 성분이 지배하든 응력은 0.6~0.8배에 떨어지고, **0.7 × (알루미늄용으로
설계된 12~100 MPa 응력장)은 여전히 PLA 피로 허용의 4~23배**다. 그게 이유의 전부다.

전박스 대비 비율(참고): Fz 0.88~0.93 · 수평 0.49~0.83 · 토크 0.42~0.79 · GRF_z 634 → 545 N.
(Fz의 높은 비율 일부는 스윙상 0을 P99에 함께 넣는 듀티 효과다 — 스탠스만 보면 0.82~0.89.)

## §3 방법 — 캠페인 파이프라인 재사용 + 검증이 잡은 규약 2건 정정

1. **하중**: `tools/fea/walk_basis.py` → `loads_walk.json`. flat 앵커(gen21p2_fc, 121명령×15 s)
   중 단순보행 박스 안의 블록(T2 25/121, 17,400 step). 이전 블록이 박스 밖이면 첫 3 s 제거
   (제거 효과 < 1 %). 링크로컬 프레임·|성분| P99 = wrench_studio `sweep`(cfrc_int→관절앵커 이송
   §8i, 자식링크 회전, 반력 부호) 그대로. ★전박스 재집계가 서버 캐시와 0.05 이내 일치(assert).
   (R다리 미러는 |성분| 통계에 영향이 없어 이 회귀로 검증되지 않는다 — 풀링·백분위만 검증.)
2. **응력**: 링크별 단위해 .frd를 `envelope.combine`으로 부호조합 포락 재합성. ★캠페인 크기로
   합성하면 기록된 최대응력을 0.04 % 이내 재현(assert 2 %). 검증 에이전트가 독자 파서·독자
   2ⁿ 스윕으로 재계산해 전 링크 일치.
3. **보행 크기 — v2 규약**: Fx/Fy/Fz = 보행 P99×1.25 · Maxial = 보행 τ P99×1.25(캠페인 상한) ·
   **Mt1 = Mt2 = |M⊥|P99×1.25/√2**(캠페인 `run_link_env.py` 규약 — v1은 /√2를 빠뜨려 힙·골반
   횡모멘트를 16~39 % 과대 입력했다) · **L1은 접지패치 규약**(Fz = GRF_z P99×1.25 = 681 N,
   Fx = Fy = 0.3 Fz = 204 N — v1은 발목 브래킷 렌치를 넣어 다른 물리량이었다) · Gbody 3 g.
   → L5 뒤 암 76.0 → **60.1**, 모터 플랜지 30.8 → 24.8, 밑창판 76.7 → **79.7**.
4. **부품**: ELSET별 체적가중 p99. 부품명 = CAD 솔리드 COM 최근접 + 위치 기반 추정명.
5. **PLA 밴드**: docs/79 — 정적 면내 25.5 / 정적 층간 11.3 / 피로 면내 3.4(SF1.5) / 피로 층간 1.13.
6. **수명 — v2**: Basquin N = 2e6·(σ_e/σ)^5.5, **σ_e = 5.1(면내) 과 1.7(층간) 둘 다 표기**.
   사이클 환산은 v1의 2.2×10⁴/h(관절 각속도 반전율, 베어링 프레팅용 수치)를 버리고 **T2 블록에서
   실측한 스탠스 개시 1.16~1.19 Hz → 4.3×10³/h(편다리 부품), 8.6×10³/h(골반)** 을 쓴다.
   면내/층간 중 어느 쪽인지는 출력 방향이 주응력에 대해 어떻게 놓이느냐라 **420배** 차이 —
   출력 방향이 정해지기 전에는 두 값 사이 어딘가다.

## §4 응력 밖의 것 셋 — 강성·끼워맞춤·온도. 셋 다 보행 속도와 무관하다

- **강성(공진)**: 고유진동수는 하중과 무관하다. PLA E 2.3 GPa면 docs/79 §8c의 모드가
  L5 횡 8.4~15 Hz → **1.9~3.4 Hz**, L3 35 → 7.9, L4 32 → 7.2 Hz — 제어대역(~2.6 Hz)에 들어온다.
  v1의 "하중 0.7배라 처짐 14~21배"는 맞지만 실격 사유는 처짐이 아니라 **모드**다.
- **베어링 끼워맞춤 상실**: 알루미늄 설계조차 Ø90에서 +30 K에 31 µm 간섭을 잃어 경압입 +
  Loctite 638 + 축방향 클램프를 쓴다(docs/64). PLA(CTE ~70 ppm/K)는 같은 +30 K에 6814 OD90에서
  **158 µm**, 6810 OD65 114 µm, CRBS808 OD96 168 µm, 6900 OD22 39 µm — 5배. 유지압은 E에
  비례해 30배 낮다. **시트를 가진 부품(힙요 하우징·힙 암·대퇴 측판·포크)은 보행 하중 이전에
  조립·첫 승온에서 실격**이다.
- **온도**: 모터 하우징 접촉 부품의 HDT 55 °C 조건 — RobStride 정격은 알루미늄 방열판 부착 기준.

## §5 단서

- 하중 프레임: loads.json의 Fx/Fy/Fz를 CAD 링크축에 얹는 **캠페인 규약을 상속**했다.
- 단순보행 = 명령 박스 기준. 넘어짐·외란·계단·기립 없음. 박스 경계(|vy|=0.5, |wz|=0.5)를
  포함하므로 "0.5 m/s 옆걸음 + 0.5 rad/s 회전 동시"도 들어 있다.
- 부품 응력은 체적가중 p99다. 피크(점응력)는 더 높다.
- "모터 프록시 접촉"은 카탈로그 외형 원통과의 근접 판정이다. 실제 체결 여부는 `bolts_all.json`
  으로 확인해야 하며 레일은 거기에 모터 체결이 없다.
- docs/80의 **PLA 강성 재해석**(하이브리드)은 V5 8.28 → 1.56 MPa처럼 유연한 부품이 하중을
  이웃에 넘기는 것을 보였다 — 이 문서의 전-알루미늄 응력장은 그 효과를 포함하지 않아 ORANGE
  부품에 대해 보수적이다. 반대로 수명은 층간 기준이면 420배 짧다. **두 방향 모두 불확실하므로
  ORANGE의 시간 수치를 설계 근거로 쓰지 말 것.**
