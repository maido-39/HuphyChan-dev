## 1. 근본원인 (측정, [[96_tracking_error_bottleneck]])
1. `error_vel_xy` = Σe/400인데 에피소드는 1000 스텝 → **2.5배**. 0.69 = 평균 0.276 m/s. (못 걸으면 오히려 낮게 나옴: iter 0–9에서 0.02–0.08)
2. 평균 0.276 = 정상상태 0.172 + 전환 과도(첫 2 s가 시간의 36 %, 오차 0.406).
3. 액추에이터는 병목 아님(AB 최대 43 %, T-N 도달 0 %). RP만 ankle_pitch 82 %·3.7 % 도달.
4. 명령 크기별 정상상태 오차: 0–0.5 **0.09** / 0.5–1.0 0.17 / 1.0–1.5 0.20 / **1.5+ 0.27**.

## 2. 문헌 (원자료: [[2026-08-24_command_box_lateral_survey]], [[2026-08-24_command_transient_survey]])
- **vy**: IsaacLab H1 **0**, G1 flat **±0.5**, humanoid-gym **±0.3**, Cassie/Digit 보행 **±0.6**·주행 ±0.75. ±1.0은 사족 계보 미튜닝 기본값(legged_gym·unitree_rl_gym·IsaacLab 템플릿). **우리는 ±1.0을 처음부터 끝까지 고정.**
- **비율**: Cassie는 속도가 오를수록 vy/vx를 **줄인다**(보행 0.40 → 주행 **0.15**). Booster T1은 vy를 vx와 같은 커리큘럼 레벨에 묶고 해상도를 절반으로. 우리는 마지막에 0.4(=1.0/2.5)로 Cassie 주행의 2.7배.
- **커리큘럼**: legged_gym·Berkeley Humanoid·우리 모두 **vx만** 램프. 우리 `VelocityStage`에는 `lin_vel_y` 필드가 있고 `curriculums.py:97`이 이미 처리한다 — **설정만 채우면 됨, 새 코드 불필요**.
- **샘플링**: 8개 코드베이스 전부 축 독립 박스, 디스크/극좌표 샘플러 없음. 유일한 완화는 legged_gym의 원점 데드존.
- **리샘플링**: 10 s 고정이 레거시, **(3,8) s는 IsaacLab 휴머노이드(Digit) 선택** = 우리와 동일 → 우리 값은 표준적.
- **명령 필터**: 주류에 없음. Cassie yaw 30 deg/s만 예외. Mini Cheetah의 ramp는 실기 시험용.
- **가속 보상**: 없음. Cassie ablation은 평활 과다 → 정지 선호를 경고.
- **캘리브레이션**: Cassie 계단 시험 1.4 지령 → **1.14 달성(18 % 갭)**, 후진 −1.0 → **−0.5(50 %)**. Berkeley Humanoid 0.051–0.116 m/s(60 s 조이스틱). **우리 AB: 1.6 → 1.48(8 %), −1.2 → −1.21(0 %), 정상상태 0.17** → 공개 수치 대비 열세가 아니다.

## 3. 우리 이력 (충돌 검토)
- [[2026-06-22_11-00_ankle_roll_peak_gaitfix_v5_or_hw]]: 당시 vy는 **±0.6**이었고, "측방 peak 수요를 만들기 위해" y-명령을 쓰되 **초반엔 낮추는 커리큘럼**이 2순위 레버로 제안돼 있었다(미실행).
- [[2026-07-12_gen2_bundle]] / [[2026-07-13_stall_relative_threshold]]: 게이트에 **"vy ±1.0 달성률 ≥ 60 %"**가 명시. 즉 vy ±1.0은 *의도된 하중 커버리지*다 — 프로젝트 목적이 **최악조건 하중 측정**이므로 최종 박스를 좁히면 전두면 하중 포락이 줄어든다([[62_policy_reward_design_review]] "in-DR 원칙": 학습 안 한 명령으로 측정하면 OOD).
- ⇒ **최종 vy는 ±1.0을 지켜야 한다.** 개선은 "초반 램프"로만 한다. 문헌의 ±0.3–0.6은 *제품 로봇의 운용 범위*이고 우리는 *사이징용 최악조건*을 만드는 중이라 목적이 다르다 — 이 차이를 노트에 명시해 둔다.
