## 2c. ★레짐 분해 발견 — 7개 정책 공통 (2026-07-12, regime_scatter 소급 캠페인)
전 리포트 §8b(명령 레짐 색분할 작동점: T-N·$\tau$-q·$\omega$-q·wrench $F_r$-$M_t$·clean vs push)에서 **정책 불문 반복 확인**된 패턴 — 측정·사이징 독트린으로 승격:
1. **구조 wrench 꼬리는 combo 레짐이 만든다**: 전 정책·전 관절에서 $F_r$/$M_t$ 극단(knee $F_r$>700N·ankle_pitch >1kN·ankle_roll $M_t$>200N·m)이 거의 전부 **복합명령**(2축+) 표본 — **단일축만 측정하면 구조 P99를 과소평가**. 복합조합 측정(2D면+코너+랜덤3D)이 필수임의 실증.
2. **열 vs 순시 사이징이 레짐으로 갈린다**(앵커 bentp2): knee **RMS-바인딩 본체 = 전진 보행**(q −0.7~−1.2 rad 저속 고토크), **클립 도달점 = 후진/combo** — 열정격은 전진 듀티로, 순시정격은 기동 과도로.
3. **전진/후진이 ankle 토크 부호를 가른다**: plantarflexion 푸시오프(−50~−85 N·m)=전진 전유, dorsiflexion(+20~25)=후진 — 발목 전동계 비대칭 듀티 근거.
4. **push는 envelope을 넓히지 않고 클립-체류 빈도를 높인다**: 전 정책서 fcp≈fc envelope(속도축 특히), 차이는 클립밴드 밀도 — §2b P99 delta 해석과 일치.
5. lateral은 hip_roll envelope만 형성(정적 외전모멘트, 저속 토크-only, T-N 동시수요 없음).

## 4. ★★peak = 제어 인공물 (중대)
다수 관절 peak가 **정확히 액추에이터 클립 상한**(flat knee/hip_roll=120.0, rough knee/hip_pitch/hip_roll=120·hip_yaw=60·ankle_pitch=90) — 단일 timestep 토크제한 포화이지 측정된 기계수요 아님. **진짜 무클립 수요는 미지, peak는 사이징 대상 아님.** peak-event count(90% 이내 표본): flat knee 1개·hip_roll 2개·GRF 1개 = 단일사건; rough knee 22개/8클러스터·ankle_roll 10개 = 광범위(그나마 신뢰). 즉 peak의 "값"이 아니라 "이 정도 사건이 발생"으로만 읽어야.

**한 줄**: 열은 RMS, 순시는 P99, 구조는 P99×SF 또는 peak상한CI — **원(raw) peak에는 절대 사이징하지 말 것**(±47%·클립 인공물). RMS/P99는 오차 얇아 신뢰. 이로써 [[64]]의 설계표에 CI·SF 근거가 붙음.

## 6. ★realizable 최악조건 — 속도캡 vs knee 속도갭 (2026-07-11, flat25b straight model_19999)
진행보상으로 **실제 2.5 m/s 추종 달성**한 정책서, "cmd를 실현가능 속도(≤2.0)로 캡하면 설계부하가 줄어드나?"를 기존 `flat25b_final.npz`를 cmd별로 분할해 검증:
| 관절 | P99 @cmd≤2.0 | P99 @2.5 | 캡 효과 |
|---|---|---|---|
| knee | 96.6 | 100.2 | **−3.6%** (거의 불변) |
| hip_pitch | 108.1 | 120.0 | −9.9% |
| hip_roll | 66.7 | 73.9 | −9.7% |
| ankle_pitch | 73.2 | 34.5 | +112%(측방·선회서 더 큼, 속도무관) |

- **★그러나 knee ω 갭은 캡해도 잔존**: cmd≤2.0에서도 knee ω **P99.9 17.9·max 25.0**(실 RS04 무부하 19.9 초과). max 26.7(2.5)→25.0(2.0)로 미미하게만 감소. **무릎 속도수요는 top-speed가 아니라 스윙 회수(swing retraction) 고유** → **속도캡으로 안 풀리고 knee 감속비(gear-down)가 근본해결**([[reference-robstride-motor-specs]]). 4절/링키지 knee 설계의 핵심 근거.
- **결론**: 부하=flat-2.5 P99×SF로 사이징(캡 강건). knee 속도는 별도로 감속비 확보(top-speed 무관). [[2026-07-10_flat25b_prog_p1]] §5/§7.

## 6c. ★★rough P2 정상상태 추종 결손 (2026-07-11 발견 — 부하값 해석 캐비앳)
15s-dwell 재측정으로 처음 계산된 rough P2 달성속도: **vx +1.5→−0.36(−24%, 역주행!)·+1.0→0.57(57%)·후진 전구간 ≈0(−1.5→+0.07)**, yaw는 50~95%. ★구 권위 p2r_wc_long(12s)도 재계산 결과 동일(+1.5→41%, −1.5→−10%) = **정책이 원래 험지(uniform rough)서 명령의 절반도 못 냈는데 지금까지 달성속도 표를 아무도 안 뽑았던 것**(리포트는 학습 reward 지표 의존 — 커리큘럼 분포는 쉬운 지형 위주). ⇒ (1) **rough 부하값은 "저속 보행" 부하**다: 미래 정책이 험지 1.5를 실제 내면 부하 상승 여지 — 설계 여유에 반영. (2) rough 재학습(flat25b P2 계보 warm-start 예정)의 **핵심 게이트 = 험지 정상상태 달성속도**(학습지표 아님). (3) uniform rough는 학습 지형분포보다 어려운 프로브임을 병기.
