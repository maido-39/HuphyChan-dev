## 3. 결론 — "다른 리워드에서도 그랬나?" = **예, 대부분 더 심했다**
1. **측방(vy) 미달은 전 계보 공통**: flat 최고 v2도 0.89/1.0, 대부분 0.3~0.6. 어떤 리워드 스택도 측방 1.0을 채운 적 없음. → 리워드 회귀가 아니라 **만성 약점 축**.
2. **rough에서 병진 붕괴는 구 계보가 훨씬 심각**: R1b/R2(Siekmann+Kd28)는 rough에서 병진을 사실상 추종 못 함(전진 6~10%·역주행, 스트레이프 0~33%) — 회전만 됐음. **현 ws6000이 역대 rough 최고 병진 추종**(그래도 목표엔 미달). R2 training error_vel_xy 2.63 vs 현 1.4-1.5도 일치.
3. **좌우 비대칭 방향은 런마다 다름**: ws6000 우세(좌상실) · Bkd6 우세 · knee220 **좌세** · R2 대칭 · bent 양측 0. → 고정 모델(URDF) 결함이 아니라 **각 학습의 확률적 수렴 편향**. (P2-final §11 무릎 kinematic 24% 비대칭과 같은 부류 — 하중은 대칭.)
4. **고속 전진 포화(~0.65)도 rough 고유 아님**: flat에서도 미성숙/저성능 런(v4, knee220)이 정확히 같은 0.63~0.67 포화를 보임. 잘 수렴한 flat은 1.2~1.44 도달. → 포화는 "덜 수렴한 정책"의 공통 시그니처.
5. **회전(yaw) 추종은 전 계보·전 지형에서 항상 온전** — 회전은 쉬운 축(제자리 발재간으로 해결).

## 4. 함의 (판정: 계속 학습, 게이트 재측정)
- ws6000의 상태는 "리워드 문제 재발"이 아니라 **(만성 측방 약점) + (rough 공통 악화) + (6-8k/15k 미성숙) + (warm-start로 DR·명령범위 iter0부터 최대)**의 중첩.
- iter 9000 게이트에서 동일 재측정: 좌 스트레이프·vx 포화 개선 기울기 확인. plateau 지속 시 rough 2단계 커리큘럼(PYG_NO_DR Phase1→램프) 재시작 검토 — [[rough-terrain-warmstart]]의 dr_factor=1.0 즉시 시작 조건이 유력 용의자.
- 측방 만성 약점: 명령 분포에서 vy 비중/범위 확인 + 대칭(mirror) 정규화가 후속 과제.

## 5. ★9000 게이트 후속 (2026-07-09 16시) — 축 churn 확정 → 재시작 결정
- **6000 vs 9000, 지형 2회씩** (지배축 달성률 평균): vx 53→**36%**, vy 48→**56%**(개선), wz 88→**27%**(붕괴). 축이 서로 **맞바꿈(churn)** — 단조 개선 아님. 낙상 0, 지형운 아님(2지형 재현).
- **결정적: 9000을 flat에서 측정** — 부모(P2-final flat: vx 81%/vy 62%) 도메인인데 자식은 **vx 26%**(vx+1.5에 후진), 회전 ±0.5 상실, 정지 명령에 후진 드리프트. **지형 난도 문제가 아니라 부모 능력의 망각**.
- 원인 확정: `MjlabOnPolicyRunner.load()`가 `common_step_counter`를 무조건 복원 → 명령 커리큘럼·dr_levels가 **iter 0부터 최대** + fresh critic 노이즈 advantage → 초기 churn 후 회복 못함.
- **조치**: ① run 중단(2026-07-09_11-45-26, 체크포인트 보존) ② `train_actor_warmstart.py`에 `PYG_FRESH_STEPS=1`(counter 0 리셋) 추가 ③ **rough Phase1 재시작**: PYG_NO_DR=1 + PYG_FRESH_STEPS=1 + actor-only warm-start(P2-final), 10000 iter → Phase2 DR 램프 예정. run: `rough_p1_nodr`.
- 교훈: **warm-start는 가중치만이 아니라 "커리큘럼 상태"도 함께 온다** — 스텝-키 커리큘럼이 있는 env로 이식할 땐 counter 처리를 명시 결정해야 함.
