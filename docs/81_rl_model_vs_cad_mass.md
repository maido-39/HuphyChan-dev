# 81. RL 모델 질량 vs 현 CAD — 하중 기준의 전제 점검 (2026-08-18)

이 캠페인의 **모든 하중**은 MuJoCo에서 RL 정책을 굴려 측정한 것이다. 그 측정은 시뮬레이터
모델의 질량·관성에 직접 의존하므로, **모델이 현 설계와 다르면 하중 기준 전체가 흔들린다.**
사용자 지시로 양쪽을 대조했다.

## §1 출처

- **RL 모델**: `mjlab/.../pygmalion/xmls/pygmalion.xml` — 바디마다 CAD에서 내보낸
  `<inertial mass=... diaginertia=...>` 블록. 바디당 메시 1개.
- **현 CAD**: `steps/fullbody_links.json`(솔리드별 체적·분류) + `actuator_proxies.json`(모터).
  질량 = 구조 ×2.70 + 체결구·베어링 ×7.85 + 모터 실측.

⚠**메시 체적으로 비교하면 안 된다** — RL 메시는 **외피**다. 예: `L_bukji_up_1` 외피 4,815.6 cm³를
알루미늄으로 채우면 13.0 kg인데 선언 질량은 5.10 kg(유효밀도 1.06). 비교는 **선언 질량 대
CAD 산출 질량**으로만 성립한다.

## §2 ★결과 — 총합은 맞고 **분포가 다르다**

| 링크 | RL kg | CAD kg | 차이 | 변화 | 확실성 |
|---|---|---|---|---|---|
| **발**(ankle_p+foot+toe) | 1.212 | **1.536** | **+0.323** | **+26.7 %** | ★**확정** — 모터 없음 |
| 정강이 shin | 2.823 | 3.255 | +0.433 | +15.3 % | 가정(RS03×2 배치) |
| 대퇴 thigh | 5.104 | 4.151 | −0.953 | **−18.7 %** | 가정 |
| 힙롤 hip_roll | 1.741 | 2.000 | +0.259 | +14.9 % | 가정 |
| 힙피치 hip_pitch | 0.967 | 0.778 | −0.189 | −19.6 % | 가정 |
| **다리 합(편측)** | **11.848** | **11.720** | −0.128 | **−1.1 %** | |

**총합은 1 % 안**인데 개별 링크는 **−20 ~ +27 %** 벌어진다.

★**발 +26.7 %는 가정이 필요 없는 확정값**이다 — 발에는 모터가 없어서 모터 배치 추정이
개입하지 않는다. 나머지는 "어느 모터가 어느 바디에 실리는가"를 내가 추정해 배분한 값이라
불확실하다(RL 모델은 바디당 메시 1개로 융합돼 있어 내역을 알 수 없다).

**질량이 원위(발 쪽)로 이동했다**: 발+정강이 4.035 → 4.791 kg (**+18.7 %**),
대퇴 이상 7.813 → 6.929 kg (−11.3 %).

## §3 세대가 다르다는 방증

RL 모델의 메시 이름은 `hip_rp` · `hip_ry` · `bukji_up` · `bukji_down` · `ankle` · `feet` ·
`feet_toe`로, 현 CAD의 `Knee2Ankle` · `L1_ankle_foot` 계열과 **명명 체계가 완전히 다르다**.
또 RL 모델은 **발목을 `ankle_pitch_link`(0.110 kg) + `foot_link`** 로 직렬 분해하는데,
현 설계는 **2-RSU 병렬**로 발목 모터 2개가 정강이에 붙는다. **다른 CAD 세대다.**

## §4 하중 기준에 미치는 영향

| 항목 | 방향 | 근거 |
|---|---|---|
| **발 착지 충격·발목 모멘트** | **과소평가** | 실제 발이 26.7 % 무겁다. 충격량은 질량에 비례 |
| 스윙 관성(고관절·무릎 토크) | 과소평가 | 질량이 원위로 18.7 % 이동 → 관성모멘트 증가 |
| 전체 GRF·CoM 궤적 | 거의 영향 없음 | 총질량 51.5 kg, 다리 합 −1.1 % |

발은 이미 **캠페인 최악 링크**(필드 SF 2.68, 피로 SF 1.52, 밑창판 점 SF 1.25)다.
그 하중이 **26.7 % 가벼운 발로 측정된 것**이므로, 여유는 보고된 값보다 작다.

⚠**정량 보정은 하지 않았다.** 충격 하중이 질량에 선형인지(착지 속도·컴플라이언스에 의존)
확인하지 않았고, 재측정 없이 계수를 곱하는 것은 [[feedback-load-basis-provenance]] 위반이다.

## §5 조치

1. **RL 모델을 현 CAD로 갱신**하고 **재측정**하는 것이 정답이다. 특히 발 질량과 2-RSU 발목
   구조. 그 전까지 발·정강이 판정에는 이 편의가 남아 있다.
2. 갱신 전이라면 **발 계열 판정에 마진을 두고 읽어야** 한다.
3. 모터 배치 가정(§2 '가정' 행)은 RL 모델 내역을 알 수 없어 확정 불가 — 신형 모델을 만들 때
   바디별 구성을 기록해 두면 다음 대조가 쉬워진다.
