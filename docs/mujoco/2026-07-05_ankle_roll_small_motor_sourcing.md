## 2. ★ 핵심 원리 — 감속비는 파워를 못 늘린다

$$P = \tau\cdot\omega \quad(\text{감속비 불변}),\qquad \tau_{out}=\tau_m R\eta,\quad \omega_{out}=\omega_m/R$$

- 감속 $R$↑ → 출력토크↑·**출력속도↓**. 파워는 그대로. → **소구경(저파워) 모터는 감속을 아무리 걸어도 한계**.
- 우리 roll 필요조건: 토크 peak 18–47 Nm **그리고** 속도 120 rpm(rough). 
- $R$의 상한: $\omega_{out}=\omega_m/R \geq 120$ → **$R \leq \omega_m/120$**. 하한: $\tau_m R\eta \geq \tau_{peak}$.
- ★ 두 조건 동시 만족 = 모터 로터 **$\tau_m\cdot\omega_m \gtrsim \tau_{peak}\cdot\omega_{peak}/\eta$** = 파워 하한. 감속으로 못 우회.

## 3c. ★ Radial/Axial 하중 — 소형 모터의 진짜 병목 (사용자 지적)

roll축 = 전후(x) → **수직 GRF가 반경(radial)하중**이 됨. foot_link 반력 실측(L+R):

| 측정 | radial P99/peak | axial P99/peak |
|---|--:|--:|
| flat C1 | 531 / **1037 N** (2.1×BW) | 90 / 388 N |
| rough R1b (구cfg) | 620 / 1469 N (2.9×BW) | 134 / 388 N |
| ★ **rough R2 (최종cfg)** | 603 / **2042 N** (4.0×BW) | — / — |

**모터 통합 베어링 정격 대비**:
- RMD-X6-60(Ø80, **크로스롤러 radial 2000N**) → R2 peak **2042N이 정격 살짝 초과**(1.02×) = 마진 없음. Ø80인데도 아슬아슬.
- 소형 QDD(RS00/DM4310 **深溝 볼베어링**): radial 정격 대개 **수백 N급** → **1.5kN 반경하중 초과 = 베어링 조기파손**. ★소형 모터 플랜지에 발을 직결하면 안 됨.

**해법 (표준)**: 반경/축/모멘트하중은 **전용 관절 베어링(크로스롤러 or 앵귤러콘택트 페어)**이 받고, **모터는 토크만 전달**(커플링/감속출력). 이러면 하중과 모터선택이 분리 → **작은 모터로도 가능**.
★ **2-RSU는 이게 내재적**: 모터가 정강이 위에 있고 로드/발판 짐벌베어링이 GRF를 받음 → **모터는 반경하중을 아예 안 봄**. = 2-RSU의 또다른 이점(직결 대비).

## 4. ★ 결론

**a) 감속비 25:1은 살짝 과함 → ~20:1 권장.** 우리 rough roll 속도 120 rpm이 병목: 260rpm급 모터에 25:1 걸면 출력 max ≈104 rpm(<120) → rough서 속도포화. **20:1이면 130 rpm** 확보하며 토크도 충분.

**b) 직경 하한 ≈ Ø57 (RS00급). Ø46(RS05)는 파워부족.** ankle_roll이 최저부하 관절이지만, flat조차 "16Nm를 93rpm에서" 내려면 RS05 150W로는 razor-edge, rough 불가. RS03(현 Ø90) 대비 **RS00 Ø57 = 명확히 작음**(무게 반, 부피 1/3).

**c) [정정] RMD-X6-60은 Ø80 = 안 작음** (base X6 335g 스펙과 혼동, 실제 X6-60은 820g/Ø80). 크로스롤러 radial 2kN은 우수하나 소구경 목적 탈락.

**c') 소구경 실현 = 작은 모터(RS00 Ø57 / DM4310) + 전용 관절 베어링 + 외부 ~2:1.** 반경하중 1.5kN은 별도 크로스롤러가 받고 모터는 토크만. 이래야 소형 모터 성립. **또는 2-RSU**(모터가 반경하중 안 봄 — 내재적 해결).

**d) DM4340(40:1) 금지** — 토크는 남지만 **속도 100rpm<우리 120** 미달.

## 5. 트레이드오프 (우리가 검토한 요소)
- **backdrivability/IMF**: 20:1 반사관성 = $N^2$=400×rotor (9:1 QDD의 ~5배). ankle_roll은 접지충격 받는 관절 → 고감속=역구동성↓=충격흡수↓·sim2real↑난이도. 저토크 roll이라 감내 가능하나 **우리 QDD 저감속 철학과 상충**하는 다운사이드.
- **backlash**: 외부 유성 20:1은 백래시↑ → roll 정밀/안정 저하. 저백래시(하모닉/예압) 권장하나 무게·비용↑.
- **아키텍처**: 전용 소형 roll 모터 = 2-RSU 공유(2×RS03 differential)에서 **serial-roll로 회귀**(구 RS03pitch+RS00roll 계열). 2-RSU 커플링 이점(양DOF 대칭 capability) 포기. pitch는 2-RSU/직결 유지하고 roll만 분리하는 하이브리드 검토 필요.
