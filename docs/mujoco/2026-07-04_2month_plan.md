**교훈(검증)**: ① RL 학습시간은 무시가능(30분) — 일정은 **HW·전장이 지배** ② **일정 킬러 1위 = 전장/CAN 브링업**(Asimov: power-on까지만 50~100시간 예산, "가장 과소평가되는 단계") ③ 킬러 2위 = 프린트부품 파손·수리 루프 ④ **MEVITA 경고: RL은 정지-서기가 보행보다 더 어려움**(속도추종 정책은 v=0에서 최약) ⑤ ★우리 51.5kg은 **모든 고속빌드 샘플(16~35kg)보다 무거움** = 파손·안전·크레인 리스크는 우리 고유 ⑥ 반박됨: "직렬모델 학습→병렬 배포" 지름길(Booster Gym) 미검증 — 기대 금지.

## 1. 판정 — 되는가?

**조건부 YES.** K-Scale이 정확히 "2개월 서기"를 했고, Asimov가 **같은 RSU 발목으로 100일 보행**까지 했음. 단 전제 3개가 성립할 때: **(a) 액추에이터 기성품 확보(이미 보유?) (b) CAD가 지금 상당 진행 (c) 전장 브링업을 1주차부터 병행**. 우리 고유 리스크 = 무게(51.5kg, 샘플 밖)와 첫 빌드 여부.

## 3. 가능 / 불가능 / 포기선

**✅ 2개월 내 가능** (base rate 근거): 2-RSU HW 완성 · 전장 브링업 · 관절 ID · 크레인 서기+제자리스텝(K-Scale 전례) · (보너스) 크레인-보조 첫 스텝
**❌ 2개월 내 불가** (증거): 강건 무보조 보행(K-Scale 1년에도 미달, peer 4개월) · 험지/달리기 정책 실기 · 신뢰성(파손 없는 운용 — K-Scale 1년) · 정밀 actuator-net
**✂ 의식적으로 포기(안 하기로)**: 외관/커버 · 야외 데모 · 상체 통합(하지 플랫폼 우선) · 보행 속도/미관 튜닝 · toe 정밀 활용(수동 스프링 그대로)
**➡ 이후(같은 HW, 정책만)**: 보행 강건화 → 험지 → 달리기 — 리비전 불필요, sim 정책 추가 학습.
