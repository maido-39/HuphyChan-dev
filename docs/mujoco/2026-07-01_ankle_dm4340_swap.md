# Ankle 모터 스왑 검토 — Damiao DM-J4340-2EC (측정데이터 판정)

> 질문: "Ankle을 DM-J4340-2EC(40:1, peak 27 N·m)로 바꾸면?" → worst-case 측정 클라우드를 현 RobStride와 DM 양쪽 TN곡선에 대조해 **데이터로** 판정.
> ★ **결론 먼저: ankle_roll엔 ✅ 정답, ankle_pitch엔 ❌ 치명적 오답.** ankle은 두 관절(roll/pitch)이 **서로 다른 모터**라 하나로 묶어 바꾸면 안 됨.

## 3. 해석

### ✅ ankle_roll → DM-J4340-2EC = **정답** (docs/49 확증)
- 현 **RS00(14/5)이 부족**: Peak 16>14(순간초과), rough T_ss 114℃(과열 근접).
- DM-J4340(27/9)로: Peak 16 **< 27**(여유 40%), RMS 40%(연속 여유), **T_ss 88→44℃**(열 문제 소멸). 토크·열 全 해결.
- 속도: ankle_roll는 저속(flat p99 63 rpm) → **무부하 100rpm 초과 운전점 flat 0.2%**뿐(docs/49 "~0.6%" 일치). rough의 2%는 OOD 헛디딤 → 재학습이 흡수.

### ❌ ankle_pitch → DM-J4340-2EC = **치명적 오답**
- ankle_pitch는 **binding 최악 관절** — RS03 60에 **상시 포화**(정책이 push-off서 60↑ 원함), RMS 22.6.
- DM은 **peak 27(RS03의 절반 이하)·rated 9** → RMS **251%**, T_ss **780℃**(즉시 소손), 클라우드 **25%가 엔벨로프 밖**.
- 속도도 p99 108 > 무부하 100rpm → 낼 수도 없음.
- **방향이 정반대**: ankle_pitch는 토크를 **더** 줘야(RS04 120 또는 감속), DM으로 **줄이면** 파탄.

### ⚠ 40:1 감속의 대가 (공통 주의)
- 40:1은 QDD(통상 6-10:1)보다 훨씬 큰 감속 → **반사관성 ∝ N² 급증** → **역구동성↓·충격흡수(IMF)↓**. 발목은 heel-strike 충격을 받으므로 백드라이브/충격완화 손해. ankle_roll은 충격 부담이 pitch보다 작아 수용 가능하나, 스펙에 명시할 리스크.
- 무부하 100rpm은 낮음 → 빠른 발 동작(스윙) 여지 축소. ankle_roll은 OK, pitch는 부적합의 한 이유.

## 4. 권고

| 관절 | 현재 | 권고 | 근거 |
|---|---|---|---|
| **ankle_roll** | RS00 (14/5) | **→ DM-J4340-2EC (27/9)** ✅ | 순간초과·과열 해결, 속도 클립 ~0.2%(flat) |
| **ankle_pitch** | RS03 (60/20) | **유지 or 상향(RS04 120/감속)** — DM 금지 | binding 최악, 60↑ 필요. DM(27)은 정반대 |

→ **"ankle을 DM으로"는 ankle_roll만.** ankle_pitch까지 바꾸면 로봇이 못 걸음. ankle_pitch 상향은 [액추에이터 평가 v2 §3](2026-07-01_actuator_evaluation.md)의 1순위 과제와 동일.

**다음**: ankle_roll=DM-J4340 + ankle_pitch=RS04(또는 감속)로 **config 반영 → 재학습 → 재측정**하면 clip 풀린 실수요로 재판정(반복 사이징).
