# 실무자 상담 분석 — 광운대 로빛(K-BOT 계열, 33kg) vs 우리 판단 재검

> 2026-07-04. 박수원 교수(DYROS)팀 실제 휴머노이드(K-BOT 파생, 33kg/1.3m) 제작자 상담. **우리 아키텍처 판단(2-RSU+knee링크)을 peer ground-truth로 검증·교정.** 관련: [직결vs2-RSU 학술분석](2026-07-04_serial_vs_2rsu_analysis.md).

## 결정-관련 신호 추출

### A. 우리 판단을 확증하는 것
1. ★ **그들도 2-RSU 채택 + 작동시킴** — 우리 학술결론(2-RSU가 capable 휴머노이드 최적) peer 실증.
2. ★ **비대칭 actor-critic** "Actor엔 쉽게 계산가능한 것만" — 내가 방금 적용한 것과 정확히 일치.
3. **CAD inertia 그대로 쓰되 DR 세게** — 우리 방침과 동일.
4. **IK 선형화 안 함, 50Hz도 충분** — 우리 50Hz 정책 정합.

### B. ★ 새로 추가되는 결정적 실무 제약 (우리가 몰랐던 것)
1. ★★ **2-RSU는 naive 관절 PD로 하면 "임피던스 안 맞아 튀고 깨짐" → Jacobian 임피던스 제어하면 잘 됨.** = 2-RSU 하려면 **처음부터 관절PD가 아니라 Jacobian-공간 임피던스 제어**를 설계해야 함($\tau=J^T$·[관절 가상임피던스]).
2. ★★ **RSU가 전체 고통의 40%, 액추에이터가 40%** = 2-RSU는 실무 비용이 거대. sim2real **4개월**(제어기 2개월 별도).
3. **LPF 필수** — 정책 q/q' 출력이 실기서 진동 → LPF 주니 잘 걸음. **RSU는 IN/OUT 둘 다 LPF.**
4. **PACE framework / lucky-ID**(robros 사용) — 실 데이터로 오프라인 sim 조정. **RS04가 명령 PD를 안 따름** → ID 필수.
5. **게인 램핑 = sim2real의 본체**: 크레인에 띄우고 ①최대한 말랑(안 떨리게)→②천천히 올려 서기→③걷기. "게인 높으면 다 부서지는 거 100% 확정."
6. **모터 제어주기**: Robstride 최대 200Hz, **안정선 150Hz**. 정책 50Hz를 3~4번 반복. 주기 짧을수록 분해능·반응↑.
7. **CAN 종단저항·패킷드랍(14ms)·모터선 고정** — 통신이 물리적 고통원.

### C. ★ 우리 판단에 도전하는 것 (정직히)
1. ★ **K-BOT ankle 토크는 walking 병목이 아니었음**("걷는것만도 빡센데 뭘 고려하나"). = 2-RSU의 **용량 pooling 이득은 생각보다 부차적**, 진짜 가치는 **limb inertia(동특성)**. → 우리 학술분석과 정합(HUBO 52% = 질량 문제지 토크 아님).
2. **33kg 로봇** — 우리 51.5kg보다 가벼움. 우리는 더 무거워 **부하 여유 없음**(knee 107%·ankle_roll RS00 과부하) → 2-RSU 이득 **우리가 더 큼**.
3. **RSU 40% 고통 + 4개월 sim2real** — 비용이 막대. one-shot·타임라인에 실질 리스크.

## 다각도 재판단

### 관점 1 — 아키텍처 (변함): 2-RSU ankle + knee 링크
학술(IMF·limb inertia) + peer 실증(2-RSU 작동) + 우리가 더 무거움 → **2-RSU가 여전히 최적**. C(도전)의 "토크는 병목 아님"은 오히려 우리 분석(질량이 핵심)과 일치.

### 관점 2 — ★ 진짜 결정은 "여부"가 아니라 "제어·sim2real 방법"
peer 데이터가 알려준 것: 2-RSU 성패는 **Jacobian 임피던스 제어 + LPF(in/out) + PACE-ID + 크레인 게인램핑** 을 **처음부터 설계하느냐**에 달림. 우리 현 sim은 관절-공간 PD(effort)라 — 이대로 배포하면 "튀고 깨짐". → **sim을 2-RSU 병렬기구로 모델링 + Jacobian 임피던스 제어로 학습**이 필수 선결.

### 관점 3 — 비용/리스크 (peer가 정량화)
- 2-RSU = 40% 고통 + 4개월 sim2real(peer 실측). one-shot이면 이 비용을 감수하는 선택.
- fallback: 직결 ankle이면 RSU 40% 고통 제거, 단 학술 페널티(원위질량→달리기 불리, HUBO 52%). peer도 "walking엔 ankle 토크 충분"이라 **직결로 걷기까진 됨**.
- → **capability(달리기·험지) vs schedule certainty**의 교환. 우리 목표가 run/rough면 2-RSU, 리스크는 방법(관점2)으로 관리.

## 결론 (peer + 학술 통합)

**아키텍처: 2-RSU ankle + knee 링크 확정** — 학술(IMF/limb-inertia) + peer 실증 + 우리 무게(이득 더 큼) 3중 근거. **imitation이 아니라 원리+실증의 수렴.**

★ 단 peer 데이터가 바꾼 것 = **실행 레시피를 처음부터 박아야 함**:
1. **Jacobian-공간 임피던스 제어**(2-RSU, 관절PD 금지) — sim 학습부터 이 구조로
2. **sim에 2-RSU 병렬기구 모델링**(mjlab equality/tendon) → 정책이 실 역학 학습 → sim2real gap↓
3. **LPF (RSU in/out)** + **150Hz 모터제어**(정책 50Hz ×3)
4. **PACE/lucky-ID**로 액추에이터 gap(RS04 PD 미추종) 오프라인 보정
5. **크레인 게인램핑**(말랑→서기→걷기) = sim2real 4개월 예산
6. 게인 시작점(peer): 직결관절 40~250/1~150, **2-RSU 가상임피던스 15/1**(우리 28.5보다 낮음 → 재검토)

**정직한 리스크**: RSU 40% 고통 + 4개월 sim2real은 실측 비용. 우리 목표(run/rough)엔 2-RSU가 옳지만, **타임라인이 이 비용을 감당하는지가 진짜 제약**. 감당 못 하면 "직결로 걷기 먼저"가 peer-실증된 fallback.
