목업 C — TX 패널 확장 "운용 모드" 카드

모드/로봇 전환은 그대로 상단에서 하되, 전송(TX) 관련 전제는 TX 패널 안 "운용 모드" 카드에서 한 번에 확인한다. 원(●)은 라디오처럼 보이지만 저장된 선택이 아니라 현재 실제 조합과 정확히 일치할 때만 채워지는 계산값이다 — 항목을 눌러도 원이 바로 안 채워질 수 있다(다른 축이 아직 안 맞으면).
불편 요소 5가지 (펼치기)
  • 로봇 정책 관측·손으로 미러링은 TX와 무관(둘 다 전송 OFF)한데도 TX 패널 안에 들어가 있어 "여기가 왜 이 얘기를 하지"라는 위치 혼동이 생긴다.
  • Target/Enable/Gains/TTL 위에 운용 모드 카드까지 얹혀 패널이 매우 길어진다(스크롤 필수).
  • "여기서 항목을 누르면 바로 전송되나?"라는 오해가 생기기 쉽다 — 실제로는 실물 동시 구동을 눌러도 별도 ARM을 눌러야 전송이 시작된다(의도적 마찰이지만 처음엔 헷갈린다).
  • 운용 모드 카드를 접으면(공간 절약) 현재 조합 이름 표시도 같이 사라진다 — 상태를 보려면 다시 펼쳐야 한다.
  • 전환마다 해제→설정→무장을 반복해야 한다 — 실물 동시 구동으로 갈 때마다 자동 해제 후 수동 ARM 클릭이 필요해, 세 조합을 자주 오갈 때 절차가 누적된다.
