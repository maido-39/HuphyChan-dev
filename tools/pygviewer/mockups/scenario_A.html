목업 A — 상단바 세그먼트/전환 스위치

기존 mode: manual 자리 옆에 전환 버튼 3개를 나란히 붙인 안. 현재 조합 이름은 버튼과 분리된 별도 읽기 전용 표시(아래 "현재" 카드)로 계산되어 나오며, 버튼 자체는 눌린 채로 남지 않는다 (액션일 뿐 상태 아님).
불편 요소 5가지 (펼치기)
  • 기존 mode 드롭다운과 개념이 겹친다 — 사용자가 모드를 직접 바꾸면 전환 버튼들이 가리키는 이름과 어긋나 즉시 "custom"으로 떨어지는데, 왜 떨어졌는지 상단바에서 바로 안 보인다.
  • 로봇 쪽 확인 상태(확인됨/모름/불일치)가 작은 칩 하나뿐이라 반쪽짜리 정보만 상시 노출된다.
  • 실물 동시 구동(위험 전환) 버튼도 다른 두 개와 나란히 있어 오클릭하면 확인 모달까지는 뜨지만 "여기 위험한 게 있다"는 사실 자체를 미리 알아채기 어렵다.
  • 상단바가 이미 혼잡한데(pill 5~6개) 전환 버튼까지 더해 두 줄이 되고, 좁은 화면에서는 가로 스크롤이 필요해진다.
  • 불가 사유를 담을 공간이 없다 — 로봇 정책 관측(S2)의 "왜 불가인지"는 툴팁(hover)에만 있고 상시 표시할 자리가 없다. custom일 때 "어느 항목이 다른지" 목록도 한 줄로 잘려 마우스를 올려야 전체가 보인다.
