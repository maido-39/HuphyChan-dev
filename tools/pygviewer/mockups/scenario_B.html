목업 B — 좌측 Scenario 탭 + 전제조건 체크리스트

전환은 액션(동사) 항목을 눌러 시작하고, 펼치면 그 조합에 필요한 3개 축(뷰어 모드/TX/로봇 프로그램)을 하나씩 개별적으로 충족시키는 체크리스트가 나온다. 상단의 "현재" 표시는 여전히 실제 상태에서 계산되며, 체크리스트를 다 채웠다고 해서 자동으로 "선택됨"이 되는 게 아니라 실제로 세 축이 맞아떨어져야 이름이 뜬다.
불편 요소 5가지 (펼치기)
  • 클릭 수가 많다 — 탭 이동 → 항목 펼치기 → 축마다 개별 버튼, 3단계를 거쳐야 완전히 전환된다.
  • 왼쪽 탭이 여섯 개나 되어 Scenario 탭을 찾는 데 한 번 더 훑어야 한다(탭 혼동).
  • 로봇 프로그램 확인 축은 안내 모드에서 "모름"으로 오래 남는다 — 사람이 직접 확인 버튼을 눌러줘야 "확인됨"이 되므로 화면에 ? 표시가 방치되기 쉽다.
  • 축을 하나씩 맞추다 실패(예: 확인 안 함)하면 "custom"으로 남는데, 되돌아갈 지점(바로 전 조합)이 명확히 표시되지 않는다.
  • 이 패널이 3D 뷰·플롯과 물리적으로 분리돼 있어(왼쪽 vs 중앙/오른쪽), 전환하면서 로봇이 실제로 어떻게 움직이는지 동시에 보기 어렵다.
