구조 해석 (FEA)

Link FEA 포스트프로세서

전신 링크의 구속·하중·나사·베어링·모터 셋업과 해석 결과를 함께 보는 메인 도구. 필드 선택(포락 vM / 안전율 / 주응력 σ1·σ3 / 응력성분 / 변위), 컬러맵과 등고선 밴드, 범위 수동 지정과 allowable 프리셋, 컬러바, 변형 형상 배율, 단면 절단, 최대·최소 마커, 클릭 프로브, 경량화 뷰(제거 가능 / 보호 / 유지).

주력데이터: link_setup_index.json + 링크별 link_setup_<링크>.json
FEA Result Viewer (발목 단품)

발목 클레비스 단품 해석 결과 뷰어. 링크 캠페인 이전에 만든 단일 파트용이며, 전신 판정은 위의 Link FEA 포스트프로세서를 쓴다.

데이터: fea_data.json

발목 2-RSU 설계

Ankle 2-RSU CAD 뷰어

실제 STEP 모델 위에서 roll-pitch 기구학, 4개 볼조인트 요동각, AB 모터 가동범위를 본다. 설계 파라미터의 함수로 유도한 관절각 수식(Fusion 파라메트릭용) 확인용.

Ankle 2-RSU Designer v2

기하 파라미터를 직접 조절하며 ROM과 토크 전달을 보는 설계기.

Ankle 2-RSU 최적화 결과

제약 최적화(Deb 3규칙 · DE) 결과와 실행 가능해 분포.

크랭크-토크 플레이어

크랭크 각도에 따른 토크 전달비를 인터랙티브하게 재생.

하중·수요 분석

Ankle Demand 3D Explorer

정책 측정에서 뽑은 발목 수요(roll-pitch 평면의 토크·속도)를 3D 서피스로 탐색.

Wrench Studio v5

관절 렌치 측정 데이터 브라우저 — 링크별 반력, 모터 토크, 케이스 비교.
